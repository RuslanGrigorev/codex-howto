# E01: Паттерн субагентов — три специализированные роли

Комплект E01 демонстрирует реализацию архитектуры мультиагентного разделения обязанностей (Separation of Concerns) в Codex CLI 0.160.0.

## Три роли субагентов

1. **Исследователь (`explorer.toml`)**:
   - Роль: анализ архитектуры, поиск точек входа, трассировка зависимостей.
   - Песочница: строго `read-only`.
   - Запрет: модификация любых файлов на диске.
2. **Исполнитель (`implementer.toml`)**:
   - Роль: реализация задачи, создание точечного минимального diff.
   - Песочница: `workspace-write`.
   - Фокус: внесение изменений strictly в рамках переданной спецификации.
3. **Ревьюер (`reviewer.toml`)**:
   - Роль: независимая верификация качества кода, аудит безопасности, проверка покрытия тестами.
   - Песочница: `read-only`.
   - Вывод: формализованный вердикт `APPROVE` или `CHANGES_REQUESTED`.

## Состав комплекта

- `README.md` — описание архитектуры делегации.
- `explorer.toml` — профиль агента-исследователя.
- `implementer.toml` — профиль агента-исполнителя.
- `reviewer.toml` — профиль агента-рецензента.
