# Процедура ревью изменений
1. Запроси diff через git diff или исследуй переданный список файлов.
2. Проверь отсутствие утечки секретов (.env, токены, приватные ключи).
3. Убедись, что существующие независимые тесты не были ослаблены или удалены.
4. Выдай не более 3 конкретных конструктивных замечаний с указанием строк.
5. Заверши вердиктом APPROVE или CHANGES_REQUESTED.
Запрещено модифицировать файлы и выполнять деструктивные команды.
