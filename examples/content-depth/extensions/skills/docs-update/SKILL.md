# Процедура обновления документации
1. Сопоставь сигнатуры функций в коде с примерами в документации.
2. Проверь наличие новых параметров в таблицах справочника.
3. Убедись, что ссылки на файлы валидны и используют относительные пути.
4. Сформируй точный diff обновления документации без переписывания не затронутых разделов.
