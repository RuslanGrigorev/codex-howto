# Процедура построения карты проекта
1. Найди корень репозитория и изучи файлы верхнего уровня (README.md, pyproject.toml, package.json).
2. Выяви ключевые директории с исходным кодом, тестами и документацией.
3. Сформируй компактное дерево каталогов не глубже 2 уровней.
4. Опиши назначение каждого ключевого модуля и способ запуска тестов.
Запрещено модифицировать файлы и запускать внешние скрипты сборки.
