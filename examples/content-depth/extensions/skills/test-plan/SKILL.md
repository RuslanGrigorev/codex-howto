# Процедура составления тест-плана
1. Исследуй сигнатуру функции, типы аргументов и возвращаемое значение.
2. Сформируй позитивные сценарии (happy path).
3. Сформируй негативные сценарии (невалидные аргументы, исключения).
4. Опиши граничные условия (0, отрицательные числа, пустые строки, предельные длины).
5. Оформи план в виде Markdown-таблицы с колонками: ID, Сценарий, Вход, Ожидаемый результат.
