# E02: Четыре практических навыка для репозитория

Комплект E02 содержит четыре готовых полнофункциональных навыка (Skills) для Codex CLI 0.160.0. Каждый навык упакован в собственный каталог с `SKILL.md` и YAML frontmatter.

## Состав навыков

1. **`project-map`**: построение карты репозитория, выявление ключевых модулей, точек входа и межпакетных связей.
2. **`diff-review`**: аудит изменений Git на утечки секретов, нежелательные зависимости и регрессии.
3. **`test-plan`**: составление плана тестирования новой функциональности с позитивными, негативными и граничными сценариями.
4. **`docs-update`**: поддержание актуальности справочников и документации после изменения сигнатур API.

## Способы вызова

```text
$project-map
$diff-review main..feature
$test-plan auth.py
$docs-update reference/commands.md
```
