# H03: Хук UserPromptSubmit для проверки и дополнения запроса

Комплект H03 демонстрирует использование хука `UserPromptSubmit` в Codex CLI 0.160.0. Хук срабатывает сразу после нажатия Enter пользователем в TUI или передачи начального промпта.

## Назначение хука

- Валидация входных данных: проверка на присутствие случайно вставленных ключей доступа или токенов перед их отправкой в языковую модель.
- Дополнение контекста: автоматическое добавление служебных префиксов или ссылок на актуальные стандарты.
- Отклонение недопустимых запросов до расходования токенов.

## Состав комплекта

- `README.md` — описание контракта события.
- `hooks.json` — конфигурация подключения.
- `prompt_guard.py` — обработчик проверки токенов и секретов.
