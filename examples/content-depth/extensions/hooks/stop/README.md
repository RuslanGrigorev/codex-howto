# H04: Хук Stop для проверки критериев завершения

Комплект H04 демонстрирует использование хука `Stop` в Codex CLI 0.160.0. Хук срабатывает в момент, когда модель считает свою задачу завершённой и собирается вернуть управление пользователю.

## Назначение хука

- Финальная валидация: проверка, что перед объявлением успеха действительно был запущен тест или линтер.
- Предотвращение ложноположительных завершений (галлюцинаций готовности): если тесты не пройдены, хук возвращает модели требование продолжить цикл и исправить дефекты.

## Состав комплекта

- `README.md` — описание механизма и сценария.
- `hooks.json` — конфигурация регистрации хука.
- `stop_verifier.py` — обработчик, проверяющий прохождение тестов и блокирующий преждевременный выход.
- `test_stop_verifier.py` — тесты fail-closed семантики и верификации флага тестов.
