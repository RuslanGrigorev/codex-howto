# H01: Хук PreToolUse для валидации вызовов инструментов

Комплект H01 демонстрирует реализацию перехватчика `PreToolUse` в Codex CLI 0.160.0. Хук позволяет динамически проверять, разрешать (`allow`), отклонять (`deny`) или модифицировать аргументы вызова инструмента до его физического исполнения в песочнице.

## Состав комплекта

- `README.md` — описание события и схемы ответа.
- `hooks.json` — конфигурация регистрации хука в проекте.
- `pre_tool_validator.py` — обработчик на Python, блокирующий опасные команды (`rm -rf`, доступ к `.env`).

## Контракт события PreToolUse

Входящие данные (stdin хука):
```json
{
  "event": "PreToolUse",
  "tool_name": "run_command",
  "arguments": {
    "command": "rm -rf /tmp/data"
  }
}
```

Ожидаемый ответ (stdout хука):
- Разрешение:
  ```json
  {"status": "allow"}
  ```
- Блокировка с объяснением причины:
  ```json
  {"status": "deny", "reason": "Удаление каталогов через rm -rf запрещено политикой репозитория."}
  ```
- Модификация аргументов:
  ```json
  {"status": "modify_args", "arguments": {"command": "safe_cleanup.sh"}}
  ```
