# H02: Хук PostToolUse для аудита результатов инструментов

Комплект H02 демонстрирует использование хука `PostToolUse` в Codex CLI 0.160.0 для аудита и логирования результатов операций.

## Важное отличие от PreToolUse

Хук `PostToolUse` вызывается **после** физического исполнения инструмента на диске. Он **не может отменить или откатить** уже совершённое действие! Его назначение — аудит, формирование логов соответствия (compliance logging) и информирование модели о потенциальных побочных эффектах.

## Состав комплекта

- `README.md` — описание механизма и ограничений.
- `hooks.json` — регистрация хука.
- `post_tool_auditor.py` — аудит логов и запись в `audit.log`.

## Контракт события PostToolUse

Входные данные:
```json
{
  "event": "PostToolUse",
  "tool_name": "edit_file",
  "arguments": {"path": "src/app.py"},
  "result": {"status": "success", "lines_changed": 15}
}
```
