# E04: Сравнение транспортов MCP — Stdio и HTTP/OAuth

Комплект E04 подробно разбирает два ключевых архитектурных транспорта Model Context Protocol (MCP) в Codex CLI 0.160.0: локальный процесс через стандартный ввод/вывод (stdio) и удалённый сервис через HTTP (SSE / REST) с потоком авторизации OAuth 2.0.

## Состав комплекта

- `README.md` — детальное сравнение транспортов и сценариев применения.
- `stdio_config_example.toml` — конфигурация локального stdio сервера.
- `remote_oauth_flow.md` — пошаговый протокол авторизации OAuth для удалённого MCP.
- `mcp_client_simulator.py` — симулятор клиента MCP с проверкой `initialize`, `tools/list`, `tools/call`, границ путей и восстановления после отказов.
- `test_mcp_simulator.py` — тесты жизненного цикла MCP, path boundary, тайм-аутов и восстановления.

## Сравнение транспортов

| Характеристика | Stdio транспорт | Удалённый HTTP / SSE |
|---|---|---|
| **Исполнение** | Дочерний локальный процесс | Удалённый веб-сервер |
| **Авторизация** | Права локального пользователя ОС | OAuth 2.0 / Bearer токен |
| **Песочница** | Ограничение путей `--root`, локальные namespaces | Сетевые политики, HTTPS TLS |
| **Задержка** | Минимальная (межпроцессные пайпы) | Сетевая (зависит от канала) |
| **Типичные задачи** | Работа с файлами, sqlite, локальными утилитами | Интеграция с GitHub, Notion, Sentry, Jira |
