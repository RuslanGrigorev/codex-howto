# E03: Анатомия плагина Codex CLI

Комплект E03 демонстрирует структуру и жизненный цикл плагина (Plugin Bundle) для Codex CLI 0.160.0. Плагин объединяет манифест `plugin.json`, специализированные навыки (`skills/`), настройки MCP-серверов (`mcp_config.json`) и нативные перехватчики (`hooks.json`).

## Состав комплекта

- `README.md` — описание структуры и правил изоляции плагина.
- `plugin.json` — декларативный манифест плагина.
- `skills/plugin-demo/SKILL.md` — встроенный навык плагина.
- `hooks.json` — конфигурация хуков плагина.
- `mcp_config.json` — конфигурация MCP-серверов плагина.
- `scripts/plugin_prompt_guard.py` — fail-closed обработчик UserPromptSubmit с фильтрацией секретов.
- `scripts/plugin_stop_verifier.py` — fail-closed обработчик Stop с проверкой тестов и recursion guard.
- `test_plugin_hooks.py` — тесты fail-closed семантики, фильтрации и защиты от зацикливания.

## Жизненный цикл плагина

1. **Распаковка**: размещение в `.codex/plugins/<plugin-name>/` или профиле пользователя.
2. **Валидация манифеста**: проверка схемы, версий и запрошенных прав доступа.
3. **Подтверждение доверия**: явное подтверждение пользователем перед активацией.
4. **Регистрация пространств имён**: вызов навыков с изоляцией имён (`$plugin-name:skill`).
5. **Чистое удаление**: удаление каталога без остаточного влияния на систему.
