# Демонстрационный навык плагина
1. Сообщи, что плагин course-extension-pack успешно активирован.
2. Проверь наличие манифеста plugin.json в каталоге плагина.
3. Выведи версию и список запрошенных прав.
Запрещено модифицировать файлы и запускать внешние команды.
