# Спецификация задачи: Исправление обработки деления на ноль

## Контекст
В учебном модуле `calc.py` функция `divide_and_round` должна делить числа и округлять результат.
При попытке деления на ноль функция ошибочно возвращает `None`.

## Требования
1. В `calc.py` при `b == 0` генерировать стандартное исключение `ZeroDivisionError("Деление на ноль запрещено")`.
2. Не изменять сигнатуру функции `divide_and_round(a: float, b: float, precision: int = 2) -> float`.
3. Сохранить округление до `precision` знаков для допустимых входных данных.
4. Не изменять проверочный файл `test_calc.py`.
5. Изменения должны быть минимальными (минимальный diff).

## Критерий приёмки
Команда `python test_calc.py` завершается с кодом `0` и выводит `PASS: B01 calc tests`.
