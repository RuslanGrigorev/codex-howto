# B01: Основной рабочий цикл Codex CLI

Этот практический комплект демонстрирует классический цикл автономной и интерактивной разработки с помощью **Codex CLI 0.160.0**:
1. Формулирование задачи с проверяемыми критериями.
2. Анализ кодовой базы агентом без деструктивных действий.
3. Формирование минимального diff для исправления.
4. Запуск независимой проверки.
5. Фиксация результата.

## Состав комплекта

- `README.md` — этот документ и пошаговый сценарий.
- `task_spec.md` — пример спецификации задачи для агента.
- `calc.py` — учебный модуль с дефектом в логике округления и деления.
- `test_calc.py` — независимый проверочный тест.
- `expected_diff.patch` — эталонный минимальный патч.

## Сценарий выполнения

### Шаг 1. Исследование дефекта

В модуле `calc.py` функция `divide_and_round(a, b, precision)` должна безопасно делить два числа, округлять результат до `precision` знаков после запятой, а при `b == 0` генерировать `ZeroDivisionError`.
Исходный код содержит ошибку: при делении на ноль возвращается `None` вместо исключения.

### Шаг 2. Запуск независимого теста до исправления

```bash
python test_calc.py
```
*Наблюдаемый результат*: тест падает с `AssertionError: Expected ZeroDivisionError`.

### Шаг 3. Запрос к Codex CLI

Команда запуска сессии:
```bash
codex --ask-for-approval on-request --sandbox workspace-write
```

Промпт для модели:
```text
Исследуй calc.py и test_calc.py.
Исправь только обработку деления на ноль в функции divide_and_round:
выброси ZeroDivisionError("Деление на ноль запрещено"), если b == 0.
Не изменяй файлы тестов и не добавляй новых зависимостей.
Покажи минимальный diff.
```

### Шаг 4. Проверка и валидация

После внесения изменений запустите повторно:
```bash
python test_calc.py
git diff calc.py
```
Тест должен завершиться с кодом `0`.
