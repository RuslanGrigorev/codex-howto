# B04: Входы, терминал и неинтерактивный режим exec

Комплект B04 демонстрирует способы подачи входных данных в Codex CLI 0.160.0: аргументы командной строки, конвейеры stdin, heredoc, а также неинтерактивную автоматизацию через `codex exec`.

## Состав комплекта

- `README.md` — описание терминальных входов и режимов.
- `batch_pipeline.py` — автономный скрипт демонстрации пакетного выполнения задач.
- `sample_task.txt` — пример входного файла со спецификацией задачи.

## Режимы подачи входных данных

### 1. Интерактивный терминальный интерфейс (TUI)
```bash
codex
```
Запускает полноэкранный интерфейс с поддержкой истории ввода, подсветки синтаксиса и интерактивных подтверждений.

### 2. Передача начального промпта аргументом
```bash
codex "Проверь синтаксис main.py"
```

### 3. Неинтерактивное пакетное выполнение через exec
```bash
codex exec "Запусти pytest и сформируй отчёт в report.txt"
```

### 4. Конвейер stdin (Pipes)
```bash
cat sample_task.txt | codex exec --stdin
```

### 5. Потоковый вывод событий в формате JSONL
```bash
codex exec --json "Исправь баг в logic.py" > session_stream.jsonl
```
