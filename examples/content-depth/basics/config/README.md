# B02: Конфигурация и профили Codex CLI 0.160.0

Этот комплект демонстрирует корректное определение параметров сессии Codex CLI, приоритеты переопределения и разделение глобальных и проектных файлов конфигурации.

## Состав комплекта

- `README.md` — описание слоёв конфигурации и команд.
- `minimal.config.toml` — базовый профиль для повседневной разработки.
- `security_audit.config.toml` — строгий профиль для инспекции и аудита кода (`read-only`).
- `check_layers.py` — автономный скрипт валидации параметров по официальной схеме тега 0.160.0.

## Слои конфигурации

1. **Флаги CLI** (`--sandbox`, `--ask-for-approval`, `-c key=value`): переопределяют всё.
2. **Именованный профиль** (`$CODEX_HOME/NAME.config.toml`): активируется через `--profile NAME`.
3. **Проектная конфигурация** (`.codex/config.toml`): настройки репозитория.
4. **Глобальная конфигурация** (`~/.codex/config.toml`): настройки пользователя.
5. **Системные умолчания**: фундаментальные ограничения безопасности.

## Примеры использования

```bash
# Запуск со строгой конфигурацией аудита
codex --profile security_audit

# Запуск с переопределением режима песочницы на лету
codex -c sandbox_mode=read-only -c approval_policy=on-request

# Проверка активных параметров внутри сессии
/debug-config
```
