# B03: Управление контекстом, сессиями и историей диалога

Комплект B03 демонстрирует работу с контекстным окном, использование команд `/status` и `/compact`, структуру хранения логов сессий в формате JSONL и предотвращение деградации внимания модели при длительной работе.

## Состав комплекта

- `README.md` — описание управления контекстом и командами.
- `session_sample.jsonl` — реалистичный фрагмент журнала сессии (события turn/start, tool_call, observation, turn/completed).
- `compact_demo.py` — демонстрационный скрипт, моделирующий извлечение сводки и сжатие истории.

## Ключевые команды

```text
/status    # Инспекция текущего расхода токенов и размера истории
/compact   # Сжатие истории диалога в краткую архитектурную сводку
/recap     # Просмотр текущей сводки контекста
/memories  # Просмотр долговременных заметок между сессиями
```

## Разделение хранилищ

- **Оперативная память (RAM)**: активное контекстное окно модели.
- **История на диске (`~/.codex/sessions/*.jsonl`)**: полная несжатая хронология всех шагов.
- **Долговременная память (`~/.codex/memories/`)**: структурированные выводы.
- **Рабочее дерево Git**: файлы проекта на диске. Сжатие сессии не откатывает Git!
