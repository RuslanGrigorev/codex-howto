# Спецификация итогового проекта

## Цель проекта
Разработать и протестировать модуль обработки и агрегации метрик производительности:
- Чтение конфигурации из `config.json`.
- Валидация входных данных по схеме.
- Вычисление перцентилей (p50, p95, p99).
- Экспорт сводки в Markdown и JSON.
- Полное покрытие независимыми тестами без сторонних библиотек.
