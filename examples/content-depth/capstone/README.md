# C01: Итоговый комплексный практикум (Capstone Project)

Итоговый проект C01 объединяет все изученные концепции курса Codex CLI 0.160.0 в единый сквозной рабочий процесс:
1. Подготовка конфигурации и политик безопасности (`config.toml`, `.rules`).
2. Настройка инструкций проекта и вложенных модулей (`AGENTS.md`).
3. Использование набора специализированных навыков (`skills/`).
4. Автоматизация контроля качества через хуки (`hooks.json`).
5. Интеграция с локальным MCP-сервером инструментов.
6. Выполнение полного цикла разработки: исследование → планирование `/plan` → минимальный diff → независимый тест → ревью.

## Состав комплекта

- `README.md` — итоговое руководство и критерии приёмки.
- `capstone_project_spec.md` — техническое задание на реализацию модуля метрик.
- `starter/metrics.py` — исходная заготовка с дефектом в расчёте перцентилей.
- `starter/test_metrics.py` — независимый проверочный тестовый набор.
- `solution/metrics.py` — эталонная реализация, удовлетворяющая всем тестам.
- `verify_capstone.py` — автономный скрипт сквозной валидации политики diff и запуска независимых тестов.
- `test_capstone_verifier.py` — мета-тесты проверки работы верификатора и политики защиты тестов.

## Критерии готовности проекта

- [ ] Все независимые тесты модуля проходят со статусом PASS.
- [ ] Отсутствуют незафиксированные или избыточные изменения в Git.
- [ ] Конфигурация соответствует профилю безопасности `workspace-write` + `on-request`.
- [ ] Документация и справочники обновлены.
