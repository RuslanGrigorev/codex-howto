# A02: Безопасный GitHub Actions Workflow для Codex CLI

Комплект A02 демонстрирует архитектуру безопасной интеграции Codex CLI 0.160.0 в конвейер непрерывной интеграции (CI/CD) GitHub Actions для проведения аудита pull request.

## Состав комплекта

- `README.md` — описание модели угроз и правил безопасности.
- `codex_review.yml` — эталонный файл рабочего процесса GitHub Actions.
- `validate_ci_workflow.py` — автономный скрипт валидации синтаксиса и безопасности workflow.

## Модель угроз и принципы безопасности в CI/CD

Автоматический запуск модели на событие `pull_request` из внешнего или недоверенного источника создаёт риск **Prompt Injection**: злоумышленник может модифицировать файлы репозитория (включая `AGENTS.md`) так, чтобы заставить модель скомпрометировать секреты или изменить код.

Для предотвращения атак эталонный workflow реализует следующие барьеры:

1. **Доверенная инициация (`workflow_dispatch`)**: модель не запускается автоматически на чужой PR; запуск производит мейнтейнер после базовой проверки diff.
2. **Изолированный checkout (`persist-credentials: false`)**: предотвращает кражу системного токена `GITHUB_TOKEN` из рабочей копии Git.
3. **Иммутабельное закрепление зависимостей**: все внешние действия (`actions/checkout`, `actions/setup-python`) закреплены по полному 40-значному commit SHA, а не по мутирующим тегам `@v4`/`@v5`.
4. **Песочница только для чтения (`--sandbox read-only`)**: агент не имеет прав на запись файлов в репозиторий.
5. **Канонический синтаксис 0.160.0**: используются `--sandbox read-only` и `--ask-for-approval always`.
6. **Защита секретов**: секреты бегуна не передаются в среду выполнения агента.
