# A04: Stdio-клиент для долгоживущего Codex App-Server

Комплект A04 демонстрирует взаимодействие с официальным долгоживущим сервером приложений `codex app-server` в Codex CLI 0.160.0.

> **Важно**: в версии 0.160.0 устаревшая команда `codex mcp-server` удалена из активного интерфейса. Официальным протоколом для IDE и хост-приложений является `codex app-server` поверх stdio.

## Протокол взаимодействия

1. **Инициализация (`initialize`)**: передача информации о клиенте и версиях API.
2. **Создание треда (`thread/create`)**: инициализация рабочего пространства и контекста.
3. **Исполнение ходов (`turn/start`)**: отправка пользовательских задач и получение потока событий `turn/event`.
4. **Управление отменой (`turn/cancel`)**: прерывание генерации без завершения серверного процесса.

## Состав комплекта

- `README.md` — архитектура и последовательность протокола.
- `app_server_stdio_client.py` — автономный клиент app-server с конечным автоматом состояний и JSON-RPC 2.0.
- `test_app_server_client.py` — модульные проверки переходов состояний, тайм-аутов и ошибок JSON-RPC.
