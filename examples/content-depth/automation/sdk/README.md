# A03: Программный клиент Python SDK для Codex CLI

Комплект A03 демонстрирует интеграцию Python-приложений с Codex CLI 0.160.0 через программный клиент SDK.

## Архитектура взаимодействия

Клиент порождает подпроцесс `codex exec` или подключается к долгоживущему процессу через `app-server`, передавая структурированные параметры и обрабатывая поток событий (streaming events) асинхронно или синхронно.

## Состав комплекта

- `README.md` — описание интерфейса SDK.
- `sdk_client.py` — законченный класс-клиент `CodexSDKClient` с абстракцией транспорта, обработкой таймаутов, кодов возврата и отказов модели.
- `test_sdk_client.py` — набор модульных проверок позитивных, негативных сценариев и отказов.
