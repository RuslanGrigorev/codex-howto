# A03: Программный клиент Python SDK для Codex CLI (ADR-CD-04)

Комплект A03 демонстрирует интеграцию Python-приложений с Codex CLI 0.160.0 через программный клиент SDK с разделением уровней абстракции и соблюдением архитектурного решения ADR-CD-04.

## Архитектура SDK

Согласно ADR-CD-04, клиент отделяет прикладной программный интерфейс от транспорта и реализации:

1. **`BaseSDKAdapter`**: базовый контракт для управления жизненным циклом сессий (`start_session`, `send_prompt`, `continue_session`, `resume_session`).
2. **`ProductionSDKAdapter`**: производственная реализация, использующая закреплённую официальную библиотеку `openai-codex==0.160.0` (недоступна в офлайн/M1 среде; вызов без установленного пакета возвращает диагностическую ошибку).
3. **`FixtureSDKAdapter`**: детерминированная реализация для тестирования и офлайн-проверок. Требует явной регистрации ожидаемых ответов; фабрикация неявного успеха для незарегистрированных промптов строго запрещена.
4. **`CodexSDKClient`**: высокоуровневый клиент для прикладного кода, предоставляющий типизированные результаты `CodexSDKResult` и исключения (`CodexRefusalError`, `CodexExecutionError`, `CodexTimeoutError`).

## Состав комплекта

- `README.md` — описание архитектуры SDK и правил изоляции.
- `requirements.txt` — закреплённая зависимость `openai-codex==0.160.0`.
- `sdk_client.py` — реализация интерфейсов адаптеров и клиента `CodexSDKClient`.
- `test_sdk_client.py` — автономные тесты адаптеров, фикстур, отказов и возобновления сессий.
