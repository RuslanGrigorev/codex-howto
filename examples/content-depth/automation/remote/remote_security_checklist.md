# Чек-лист безопасности при удалённом запуске Codex CLI

- [ ] Служба слушает строго loopback интерфейс `127.0.0.1`.
- [ ] Порт не опубликован во внешнюю сеть и защищён межсетевым экраном.
- [ ] Передача учётных данных и токенов осуществляется через SSH / TLS.
- [ ] В сессии активирован `sandbox_mode = "workspace-write"`.
- [ ] Личные ключи SSH (`~/.ssh`) и токены исключены из видимости агента через `.rules`.
- [ ] Автоматическое удаление временных файлов сессий после завершения сеанса.
