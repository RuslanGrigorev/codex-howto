# A05: Удалённый запуск, SSH/TLS и сравнение с облачными окружениями

Комплект A05 разбирает особенности работы Codex CLI 0.160.0 в удалённых окружениях: запуск через SSH, проброс портов (loopback port forwarding), взаимная TLS-аутентификация и фундаментальные отличия от закрытых облачных окружений.

## Состав комплекта

- `README.md` — концептуальный разбор и команды туннелирования.
- `remote_security_checklist.md` — контрольный список безопасности для удалённого развёртывания.

## Ключевые аспекты удалённого развёртывания

1. **Привязка к локальному адресу (Loopback Binding)**:
   При поднятии сетевых интерфейсов или app-server сервер обязан слушать строго `127.0.0.1` или `localhost`. Привязка к `0.0.0.0` категорически запрещена.
2. **Безопасный доступ через SSH туннель**:
   ```bash
   ssh -L 8080:127.0.0.1:8080 user@remote-build-server
   ```
3. **Разграничение сред**:
   Локальный CLI исполняется в изолированной песочнице хоста, тогда как облачные контейнеры требуют полной синхронизации репозитория через Git.
