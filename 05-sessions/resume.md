# Продолжение сессии не восстанавливает файлы

## Чему вы научитесь

Продолжить нужный разговор и отдельно проверить текущее состояние файлов.

## Что нужно перед началом

Сначала пройдите: [Начало: что изучаем и как проверяем результат](../01-start/overview.md). Учебные файлы входят в поставку. Установленные программы и доступ к модели требуются только для соответствующей практики.

Для выбора сохранённого разговора используйте `codex resume`; для последнего — подходящий вариант `--last`, сверенный через справку. `codex fork` создаёт ответвление беседы. Не выдумывайте `codex session list`: это не интерфейс выбранной версии.

```bash
codex resume --help
codex resume
codex fork --help
```

Возобновлённая беседа может описывать старое состояние, тогда как файлы уже изменены другим процессом. Поэтому перед продолжением заново проверьте рабочий каталог и diff. Архивирование, удаление беседы и Git-восстановление — разные операции.

## Практика

В отдельной учебной папке создайте беседу, затем вручную измените безопасный файл. Возобновите беседу и попросите сначала проверить текущее содержимое, а не полагаться на память. Зафиксируйте, что сессия сама не откатила файл.

Вспомогательный `SessionManager` из `session-restore` иллюстрирует раздельность истории и файлов. Он не читает внутреннее хранилище Codex и не подтверждает нативное `resume`. Эталон и тесты относятся только к учебной модели данных.

## Проверяемое упражнение

Выполняйте команды из корня репозитория или из `source` готового офлайн-пакета. Подготовка не перезаписывает существующую работу.

```bash
python scripts/verify.py --prepare session-restore
# Измените файлы в .learning/workspaces/session-restore
python scripts/verify.py --exercise session-restore --workspace .learning/workspaces/session-restore
```

Проверка запускает независимый `examples/session-restore/test.py`, а не тест из рабочей папки. Эталон находится в `examples/session-restore/solution`; открывайте его после собственной попытки. Тестируемый Python-код исполняется на вашей машине: запускайте только доверенные учебные файлы. Ограничение пути не является OS-песочницей.

## Что считается выполнением в Codex

Без модели доступны весь текст, вопросы, исходники и локальные тесты. Они не подтверждают работу CLI. Для практики сохраните версию `codex --version`, модель, провайдера и обезличенный результат реального запуска. Отметку можно внести через `scripts/progress.py` после проверки, согласно [правилам валидации](../reference/validation.md). Самоотчёт ученика не заменяет выпускные доказательства проекта.
