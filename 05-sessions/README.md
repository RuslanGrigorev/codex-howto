# Сессии и восстановление

Продолжать разговоры, разделять задачи и восстанавливать файлы средствами Git.

В модуле 5 уроков. Каждый урок имеет собственный результат, пример и проверку знаний. Практика с настоящим клиентом отмечена отдельно от автономного разбора.

## Уроки

### 1. [Продолжение сессии не восстанавливает файлы](resume.md)

Продолжить нужный разговор и отдельно проверить текущее состояние файлов.

### 2. [Побочные вопросы и управление беседами](side.md)

Разделить основной разговор и побочный вопрос, не создавая путаницу с изменениями проекта.

### 3. [Ветки, worktree и безопасное восстановление](worktrees.md)

Использовать отдельное рабочее дерево Git для независимой задачи.

### 4. [Архивирование и удаление сохранённых сессий](archive.md)

Различать продолжение, архивирование и необратимое удаление истории.

### 5. [Восстановление файлов: Git не равен истории чата](restore.md)

Сохранять исходную точку и осознанно отменять только собственные учебные изменения.

## Как проходить

Начните с первого урока или выберите нужную задачу. Раздел «Что нужно перед началом» указывает зависимости. Открывайте подсказку после самостоятельной попытки; отсутствие модели не мешает чтению и разбору, но реальный запуск не засчитывается.
