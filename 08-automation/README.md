# Автоматизация Codex CLI

Управлять неинтерактивным процессом, событиями JSONL, итогом по схеме и повторными запусками.

В модуле 6 уроков. Каждый урок имеет собственный результат, пример и проверку знаний. Практика с настоящим клиентом отмечена отдельно от автономного разбора.

## Уроки

### 1. [codex exec: процесс и события JSONL](non-interactive.md)

Запустить неинтерактивную задачу и корректно обработать завершение процесса и события.

### 2. [JSONL: ход выполнения, ошибки и итоговый ответ](events.md)

Разбирать поток реальных событий и не принимать пустой или оборванный вывод за успех.

### 3. [Итог по JSON Schema и продолжение exec](structured.md)

Получить итог по JSON Schema и не перепутать его с потоком JSONL.

### 4. [Повторный запуск и продолжение автоматизированной задачи](retry.md)

Безопасно повторять сбойный запуск и отличать новую задачу от продолжения существующей.

### 5. [Автоматизация в CI без выдачи лишних прав](ci.md)

Спроектировать проверяемый запуск в CI с минимальными правами и явными условиями отказа.

### 6. [Граница CLI, MCP server и app-server](app-server.md)

Различать обычный CLI, MCP server и app-server и выбрать подходящий интерфейс интеграции.

## Как проходить

Начните с первого урока или выберите нужную задачу. Раздел «Что нужно перед началом» указывает зависимости. Открывайте подсказку после самостоятельной попытки; отсутствие модели не мешает чтению и разбору, но реальный запуск не засчитывается.
