## Неинтерактивный режим (`--non-interactive`)

По умолчанию Codex CLI запускается в интерактивном режиме с ожиданием команд от пользователя через TTY. Для запуска в составе автоматических тестов, pre-commit хуков или GitHub Actions используется флаг неинтерактивного режима:

```bash
# Запуск единичной команды с завершением после выполнения
codex --non-interactive "Выполни проверку типов и выведи найденные ошибки"
```

В неинтерактивном режиме:
- CLI не запрашивает ввод с клавиатуры.
- При необходимости подтверждения опасных действий процесс завершается с ошибкой, если не заданы соответствующие политики разрешений.
- Возвращается понятный код завершения процесса:
  - `0`: задача успешно выполнена.
  - `> 0`: произошла ошибка (синтаксическая, логическая или отказ в доступе).

## Потоковый вывод событий (`--stream-json`)

Для мониторинга прогресса в реальном времени Codex CLI предоставляет структурированный вывод событий в формате **JSON Lines (JSONL)**:

```bash
codex --stream-json "Запусти тесты"
```

Каждая строка вывода представляет собой отдельный валидный JSON-объект:

```jsonl
{"type": "item_started", "id": "step-1", "timestamp": 1728000001}
{"type": "item_delta", "id": "step-1", "delta": "Запуск тестов...\n"}
{"type": "item_completed", "id": "step-1", "status": "success"}
{"type": "done", "exit_code": 0}
```

> [!IMPORTANT]
> **Различие JSONL и единичного JSON:**
> Формат JSONL **НЕ** является одним большим массивом JSON (`[...]`). Каждая строка — самостоятельный объект, отделенный символом переноса строки (`\n`). Это позволяет обрабатывать события потоково, не дожидаясь завершения всей работы.

## Обработка ошибок в скриптах

Пример парсинга в Python:

```python
import json
import subprocess

proc = subprocess.Popen(
    ["codex", "--stream-json", "Проверь форматирование"],
    stdout=subprocess.PIPE,
    text=True,
)

for line in proc.stdout:
    line = line.strip()
    if not line:
        continue
    event = json.loads(line)
    if event.get("type") == "error":
        print(f"Ошибка агента: {event.get('message')}")

proc.wait()
if proc.returncode != 0:
    print(f"Сбой с кодом {proc.returncode}")
```

## Практическое упражнение: `cli-stream`

В этом упражнении вы реализуете парсер потока `CodexStreamParser`, который:
1. Построчно читает поток событий JSONL.
2. Собирает текстовый вывод задачи из событий `item_delta`.
3. Корректно определяет ошибки (`type: "error"`) и статус завершения (`type: "done"`).
4. Защищен от зависания и ошибок поврежденных данных.
