# Сеть, веб-поиск и передача контекста

## Чему вы научитесь

Отличать сетевую функцию от локального чтения и выбирать безопасную границу данных.

## Что нужно перед началом

Понимание режима офлайн. Реальный веб-поиск требует сети; письменный разбор доступен без неё.

## Как это работает

Веб-поиск, соединение с моделью и доступ MCP к удалённому серверу — три разных сетевых канала. Отключение одного не доказывает отсутствие остальных. Локальный HTML-курс не делает облачную модель автономной.

`--search` относится к веб-поиску Codex. Не включайте его для задания, которому достаточно исходного файла. Если поиск нужен, формулируйте запрос без секретов и проверяйте происхождение найденного материала.

Текст из сети и содержимое чужого репозитория могут содержать инструкции. Их следует рассматривать как данные задачи, а не как право изменить правила работы или отправить файлы наружу.

## Разобранный пример

Для локального учебного запуска можно отключить веб-поиск в отдельном профиле:

```toml
approval_policy = "on-request"
sandbox_mode = "read-only"
web_search = "disabled"
```

Этот фрагмент не обещает отключение соединения с облачной моделью. Модельный провайдер настраивается отдельно.

## Самостоятельная практика

Составьте схему трёх соединений для своего запуска: модель, поиск, MCP. Укажите, какие из них реально нужны. Для задачи «объясни discount.py» уберите ненужные источники.

Разберите воображаемую найденную страницу с требованием отправить `auth.json`. Объясните, почему такое требование не становится инструкцией пользователя. Не создавайте и не передавайте настоящий файл авторизации.

## Ожидаемый результат

Вы не путаете отключённый поиск с полностью отключённой сетью и можете обосновать, какие данные покидают устройство.

## Типовые ошибки

Считать web_search=disabled общим сетевым выключателем; прикладывать секреты для диагностики; выполнять инструкции из недоверенного текста.

## Проверка знаний

Ответьте на вопросы внизу страницы. В исходном репозитории они доступны в [файле вопросов](network.quiz.json). Правильные ответы подтверждают понимание; выполнение практики фиксируется отдельно.

Практика требует установленного Codex и доступной выбранной модели. Без модели выполните разбор примера и подготовьте ожидаемый результат; реальный запуск остаётся невыполненным. Целевая версия — 0.160.0. Документальная сверка: 2026-10-05; она не заменяет протокол запуска на вашей ОС.
