# Термины курса

| В тексте уроков | Оригинал и смысл |
| --- | --- |
| Что нужно перед началом | Предыдущие знания, доступы и подготовка; это не всегда программные зависимости |
| Зависимости | Программы, пакеты либо явно указанные предыдущие уроки |
| Навык | `skill`: инструкции и вспомогательные файлы, обнаруживаемые Codex |
| Песочница | `sandbox`: ограничения среды выполнения; не обещание безопасности произвольного кода |
| Подтверждение действия | `approval`: решение о конкретном запросе согласно действующей политике |
| Обработчик события | `hook`: программа, подключённая к определённому событию |
| Проверка знаний | Вопросы с объяснением результата; не защита от намеренного просмотра ответов |
| Эталонное решение | Разобранный пример, проходящий независимый локальный тест |
| Пример с намеренной ошибкой | Отрицательный контроль, который должен быть отклонён тестом |
| Реальный запуск | Наблюдаемый запуск целевого CLI; текстовая имитация не подходит |
| Кандидат на выпуск | Собранный пакет, ещё не прошедший все условия публикации |

`PASS`, `FAIL`, `BLOCKED`, `NOT_RUN` и `SKIP` — машинные статусы отчёта. В интерфейсе им соответствуют «пройдено», «ошибка», «заблокировано», «не запускалось» и «пропущено». Только `PASS` закрывает обязательную проверку.
