# Режимы прохождения и требования

Учебник, проверки знаний, исходники и эталоны доступны локально. Python-упражнения требуют заранее установленного Python 3.11+, Git-практика — Git, реальный наставник — Codex и доступную модель.

Офлайн-режим не означает автоматическую доступность облачной модели. Подготовленная локальная модель через поддерживаемый провайдер проверяется отдельно. Записанный диалог помогает учиться, но не считается реальным выполнением задачи.
