# Спецификация навыков (Skills) в Codex CLI

Навыки (Skills) представляют собой модульные пакеты инструкций, расширяющие контекст агента для решения специализированных задач.

## Структура каталога навыка

Каждый навык располагается в отдельной поддиректории:
```text
.agents/skills/<skill-name>/
└── SKILL.md
```

## Требования к `SKILL.md`

1. **YAML frontmatter**: Обязательный блок в начале файла, ограниченный строками `---`.
   - `name`: Уникальный slug навыка в нижнем регистре (только буквы, цифры, дефисы).
   - `description`: Краткое (1-2 предложения) описание назначения навыка. Модель использует это описание для определения релевантности задачи.
2. **Тело инструкции**: Подробное описание последовательности действий, шаблонов ответов, проверочных критериев и правил обработки исключений.

## Правила изоляции и безопасности

- Навыки не должны содержать жестко зашитых путей текущей файловой системы автора (`C:\...`, `/home/...`).
- Запрещено требовать передачи приватных токенов в теле навыка.
- Запрещено маскировать встроенные системные команды под пользовательские навыки.
