# Справочник команд Codex CLI (Версия 0.160.0)

Этот документ является автономным офлайн-справочником команд Codex CLI. Все примеры проверены на целевой версии `rust-v0.160.0` и не требуют подключения к сети Интернет.

## Основные команды

### Запуск и интерактивный сеанс

```bash
# Запуск интерактивной сессии в текущей рабочей директории
codex

# Запуск с начальным пользовательским запросом
codex "Проанализируй структуру проекта и составь план рефакторинга"

# Вывод версии CLI
codex --version

# Вывод встроенной справки по всем доступным флагам
codex --help
```

### Управление сессиями диалога

Codex CLI сохраняет сессии локально, что позволяет продолжать прерванную работу или исследовать альтернативные ветвления.

```bash
# Вывести список сохраненных сессий с ID и временем создания
codex session list

# Возобновить сессию по ее уникальному идентификатору
codex resume <session-id>

# Быстрое возобновление самой последней активной сессии
codex resume --last
```

> [!NOTE]
> Возобновление сессии восстанавливает историю рассуждений агента, но не изменяет физические файлы на диске. Управление файловым состоянием осуществляется через Git (`git restore`, `git checkout`).

### Режимы безопасности и песочницы

```bash
# Запуск в режиме строгой песочницы (запрет записи за пределы workspace)
codex --sandbox workspace-only

# Запрос явного подтверждения перед выполнением команд и записью файлов
codex --ask-for-approval on-write

# Запуск в режиме только для чтения (исследование кодовой базы)
codex --read-only
```

### Неинтерактивный режим и автоматизация

Для CI/CD и пакетной обработки Codex CLI поддерживает работу без интерактивного терминала:

```bash
# Запуск единичной задачи без интерактивного ввода
codex --non-interactive "Выполни запуск тестов и выведи сводку"

# Потоковый вывод событий в формате JSON Lines (JSONL)
codex --stream-json "Проверь синтаксис файлов"
```
