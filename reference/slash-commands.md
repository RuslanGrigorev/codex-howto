# Локальный каталог slash-команд

Снимок статического перечня Codex **0.160.0**, сверенный с официальным исходником. Это справочник назначения, не обещание доступности всех команд в каждом окружении. Разрешения, ОС, экспериментальные флаги и каталог моделей влияют на видимость. Для аргументов откройте подсказку установленного клиента. Все команды ниже вводятся **внутри Codex**.

Подробный маршрут длительной задачи: [урок /plan и /goal](../02-workflow/plan-goal.md). Дополнительные инструкции — [справочник запуска](commands.md).

## Модель и разрешения

| Команда | Назначение |
| --- | --- |
| `/model` | Выбор доступной модели и её параметров. |
| `/permissions` | Просмотр и выбор разрешений. |
| `/setup-default-sandbox` | Настройка повышенной песочницы Windows при наличии соответствующего режима. |
| `/sandbox-add-read-dir` | Дополнительный доступ на чтение к абсолютному каталогу в нативном Windows-клиенте. |
| `/approve` | Повторная попытка недавнего действия после отказа автоматического ревью; не снятие всех ограничений. |
| `/experimental` | Управление экспериментальными возможностями. |

## Псевдонимы и динамические возможности

`/cwd` — псевдоним `/pwd`, `/clean` — `/stop`, `/pet` — `/pets`. Команды `/fast` и `/personality` могут определяться доступным каталогом возможностей; их нельзя выявить только поиском enum в исходниках. Явный вызов навыка `$learn` не входит в этот перечень встроенных команд.

`/import` может упоминать другие продукты как источник настроек. Это описание нативной возможности Codex, а не включение другого учебного направления. Отладочные операции не включаются в обязательную практику обычного пользователя.
