# Справочник конфигурации Codex CLI

Этот документ описывает структуру и параметры конфигурации Codex CLI.

## Иерархия файлов конфигурации

Codex загружает конфигурацию в следующем порядке приоритета (от высшего к низшему):

1. **Флаги командной строки** (например, `--sandbox workspace-only`).
2. **Локальный файл проекта**: `.codex/config.toml` в корне текущего репозитория.
3. **Глобальный файл пользователя**: `~/.codex/config.toml` в домашнем каталоге.

> [!CAUTION]
> Учебные задания и примеры курса **никогда** не должны модифицировать глобальный файл `~/.codex/config.toml`. Все настройки проекта должны быть изолированы в каталоге репозитория.

## Формат `config.toml`

Пример конфигурационного файла проекта:

```toml
# Модель и провайдер
[model]
name = "codex-standard"
temperature = 0.2

# Политика безопасности и разрешений
[permissions]
sandbox = "workspace-only"
confirm_dangerous_commands = true
allowed_write_paths = ["./src", "./tests", "./docs"]
blocked_paths = [".git", ".env*", "*.key"]

# Подключение локальных инструментов (MCP)
[mcp]
enabled = true

# Поведение при неинтерактивном запуске
[automation]
timeout_seconds = 300
```
