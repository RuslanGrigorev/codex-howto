# События hooks: локальная карта

Hook — обработчик события жизненного цикла, а не безусловная системная защита. Формат результата зависит от события. Нельзя возвращать решение `PreToolUse` для любого события или считать, что один обработчик не даст запуститься остальным.

| Событие | Когда полезно | Что проверять |
| --- | --- | --- |
| `SessionStart` | Подготовка сессии | Какие данные и контекст добавляются; права процесса |
| `SubagentStart` | Запуск дочернего агента | Применимость к роли, отсутствие лишних секретов |
| `UserPromptSubmit` | Отправка пользовательского запроса | Не изменяется ли смысл запроса незаметно |
| `PreToolUse` | Перед инструментом | Имя инструмента, вход и обоснованное allow/deny-решение |
| `PermissionRequest` | Запрос дополнительного разрешения | Область действия и ограничения ответа |
| `PostToolUse` | После инструмента | Фактический результат; событие не откатывает уже выполненное действие |
| `PreCompact` / `PostCompact` | До / после сжатия контекста | Отделение состояния беседы от файлов |
| `SubagentStop` | Окончание работы субагента | Проверяемый результат дочерней задачи |
| `Stop` | Завершение хода | Условия завершения, отсутствие бесконечного возобновления |
| `Interrupt` | Прерывание основной работы | Не использовать как гарантию завершения каждого подпроцесса |
| `SessionEnd` | Завершение основной сессии | Безопасность очистки и отсутствие потери результата |

Эта карта помогает выбрать урок, но не заменяет протокол каждого события. Учебный исполняемый пример реализует **только PreToolUse**. Для остальных нужен отдельный проверенный сценарий до заявления об интеграционной совместимости.

## Последовательность проверки

Сначала прочитайте конфигурацию и код. Затем подайте сохранённый JSON в процесс, проверьте stdout, stderr и код завершения. Только после этого подключите hook в изолированном профиле Codex, подтвердите именно эту версию определения и проверьте положительный и отрицательный запросы. Несколько подходящих обработчиков могут запускаться параллельно; не рассчитывайте на последовательное выполнение.
