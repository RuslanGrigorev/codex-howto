# Клавиши и ввод в Codex CLI

Клавиши относятся к терминальному клиенту, а не к браузерному курсу. Перед изменением сочетаний откройте `/keymap`: терминал и собственные настройки могут перехватывать ввод. Развёрнутый пример — [урок об интерфейсе](../01-start/interface.md).

| Действие | Ввод по умолчанию | Проверка |
| --- | --- | --- |
| Прикрепить путь файла | `@` | В запрос попал именно выбранный путь, а не одноимённый файл |
| Найти предыдущий запрос | `Ctrl+R` | `Enter` выбирает совпадение, `Escape` отменяет поиск |
| Вернуть черновик из истории | `Up` / `Down` | Текст ещё не отправлен |
| Скопировать завершённый ответ | `Ctrl+O` или `/copy` | Буфер содержит последний законченный ответ, не текущий частичный |
| Добавить инструкцию в текущую работу | `Enter` при работающем Codex | Инструкция относится к текущему ходу |
| Поставить сообщение на следующий ход | `Tab` при работающем Codex | Сообщение остаётся в очереди до следующего хода |
| Изменить предыдущий запрос | Два `Escape` при пустом поле | Создаётся ответвление разговора, файлы не откатываются |
| Очистить только вид терминала | `Ctrl+L` | Текущий разговор сохраняется |
| Начать новый разговор с очисткой | `/clear` | Контекст разговора сбрасывается; это не удаление файлов |
| Завершить CLI | `Ctrl+C`, `/exit` или `/quit` | Сначала сохраните нужные изменения и проверьте фоновые действия |

Строка с `!` запускает локальную команду под действующими ограничениями. Это не способ обойти песочницу. Для чтения состояния учебного проекта подходит `!git status --short`; команды удаления и публикации для эксперимента не нужны.

## Проверка на практике

Отправьте небольшую задачу только на чтение. Пока она выполняется, поставьте уточнение в очередь через `Tab`. Затем сравните это с вводом через `Enter` на другой безопасной задаче. Запишите наблюдение своими словами. Без работающего клиента разберите отличие по таблице; не отмечайте нативный запуск.
