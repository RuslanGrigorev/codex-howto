# Происхождение и атрибуция

Этот независимый русскоязычный практикум основан на учебной инфраструктуре проекта **Claude How-To** (репозиторий `luongnv89/claude-howto`). Название здесь указывает происхождение, а не поддерживаемое учебное направление. Действующий курс посвящён только Codex CLI.

Исходные уведомления об авторстве и условия MIT сохранены без замены в файле `LICENSE`. При распространении производной версии они должны оставаться в репозитории и автономном пакете. Права на изменения принадлежат их соответствующим авторам в пределах применимой лицензии; этот документ не переоформляет чужое авторство.

Codex и OpenAI упоминаются для обозначения изучаемого инструмента. Проект не является официальным продуктом, не аффилирован с OpenAI и не гарантирует поддержку компанией. Фирменные логотипы, модельные веса, авторизация пользователей и шрифтовые файлы не включаются в поставку.

Внешняя документация цитируется как источник технического поведения; учебные объяснения написаны для этого курса. Полные сторонние сайты и их интерфейсы не копируются в ZIP. Системные шрифты браузера не распространяются вместе с проектом.

Зависимости сборки устанавливаются отдельно: Jinja2 (BSD-3-Clause), markdown-it-py (MIT), Beautiful Soup (MIT). Они не встраиваются в браузерный JavaScript и не включаются пакетами Python в офлайн-поставку. Перед добавлением новых ресурсов проверьте их лицензию и сохраните необходимые уведомления. Итоговая лицензионная проверка владельцем остаётся отдельным условием релиза.
