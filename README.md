# Codex CLI · Практикум на русском

Независимый учебный проект для **Codex CLI**, не официальный продукт OpenAI. Текущая редакция содержит 62 урока в десяти модулях, локальный справочник, проверки знаний и девять проверяемых Python-упражнений. Основной интерфейс и объяснения — на русском; команды и имена API остаются в оригинале.

**Статус: кандидат, не подтверждённый публичный релиз.** Целевая версия Codex — 0.160.0. Документальная сверка не заменяет реальный запуск: `sources.json` сохраняет `tested_cli: null`, пока владелец не приложил необходимые доказательства. Покрытие всех деталей официальной документации пока не заявлено.

## Ученику

В готовом автономном пакете откройте `index.html`. Браузеру не требуется сеть для чтения, поиска, проверок знаний и импорта/экспорта прогресса. Исходники, подсказки и эталонные решения открываются на локальных страницах «Материалы»; оригиналы файлов доступны в каталоге `source`. Python 3.11+, Git, Codex и модель готовятся отдельно до работы без Интернета; они не включены в ZIP.

В исходном репозитории начните с [введения](01-start/overview.md). Режим длительной задачи описан в отдельном [уроке /plan и /goal](02-workflow/plan-goal.md). Общий [справочник](reference/README.md), [slash-команды](reference/slash-commands.md), [настройки](reference/config.md) и [границы покрытия](reference/coverage.md) доступны локально.

Для наставника запустите Codex в корне репозитория и введите `$learn`. Это навык проекта, а не встроенная `/learn`. Без доступной модели остаются весь учебник, проверки знаний, упражнения, подсказки и эталоны. Непроведённый запуск Codex не засчитывается.

```bash
python scripts/verify.py --prepare small-fix
# Измените .learning/workspaces/small-fix/discount.py
python scripts/verify.py --exercise small-fix --workspace .learning/workspaces/small-fix
```

Команды выполняются из корня исходников, а в готовом пакете — из `source`. Проверки используют тесты из `examples`, не из редактируемой папки. Python-код упражнения запускается на вашей машине: используйте доверенные учебные файлы. Экспортируйте браузерный прогресс перед обновлением; импортируйте `.learning/progress.json` после локальной практики. Автоматической синхронизации нет.

## Разработчику

Зависимости сборки устанавливаются заранее. Для JS unit-проверки разработчику также нужен Node.js 22 или новее. Ученик готового ZIP не обязан собирать сайт или устанавливать эти пакеты.

```bash
python -m pip install -r scripts/requirements-dev.txt
python -m playwright install chromium
python scripts/verify.py --profile offline
python scripts/package_course.py --site .learning/site
```

Последняя команда создаёт **кандидат** `.learning/dist/codex-course-candidate.zip`, а не разрешение на публикацию. При наличии системного Chromium проверка браузера использует его; можно явно указать путь в `COURSE_CHROMIUM`. Папка `.learning` не коммитится.

Сборщик не скачивает шрифты, CDN или JavaScript. Он отклоняет опасные пути вывода и не очищает произвольные каталоги. Статический сайт использует Python, Jinja2 и Markdown; сервера приложения, аккаунтов и базы данных нет.

## Выпуск и обновление

[Правила валидации](reference/validation.md) разделяют локальные проверки, реальные модельные сценарии и ручную редакционную приёмку. `validation.json` — обязательный набор допуска к релизу. `FAIL`, `SKIP`, `BLOCKED`, `NOT_RUN`, отсутствие доказательства и несовпадение хешей блокируют выпуск.

Обновлятор выполняет сетевые действия только с `--fetch`, сохраняет наблюдения отдельно и не устанавливает CLI. Неполный исходный снимок даёт `INCOMPLETE`; это ожидаемый честный статус, пока полный набор источников не собран и не проверен.
