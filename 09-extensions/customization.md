# Настройки интерфейса и экспериментальные возможности

## Чему вы научитесь

- Кастомизировать внешний вид и горячие клавиши терминального интерфейса Codex CLI (TUI).
- Управлять темами оформления (`/theme`), строкой статуса (`/statusline`), заголовком окна (`/title`) и режимом ввода Vim (`/vim`).
- Проверять и осознанно включать экспериментальные функции через `/experimental` и команду `codex features`.
- Сохранять стабильность рабочего процесса и быстро откатывать нестабильные настройки.

## Что нужно перед началом

- Терминал с поддержкой ANSI-цветов и современных шрифтов (Windows Terminal, iTerm2, Kitty).
- Установленный Codex CLI 0.160.0.
- Базовое понимание структуры конфигурационного файла `~/.codex/config.toml`.

## Схема процесса

Иерархия применения настроек кастомизации и экспериментальных фич:

```
┌────────────────────────────────────────────────────────┐
│             ~/.codex/config.toml (Глобально)           │
├────────────────────────────────────────────────────────┤
│ theme = "dracula"                                      │
│ keymap = "vim"                                         │
│ experimental_features = ["fast-compact", "git-graph"]  │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│             Интерактивная сессия Codex CLI             │
├────────────────────────────────────────────────────────┤
│ Динамическое переключение через команды:               │
│ - /theme light / dark / system                         │
│ - /vim (переключение режима модального ввода)          │
│ - /statusline (настройка отображаемых метрик)          │
│ - /experimental (просмотр и тестирование новых фич)    │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
[Эффект применяется немедленно без потери истории диалога]
```

## Команды и параметры

Интерактивные слеш-команды кастомизации интерфейса:

```text
# Смена цветовой темы оформления TUI
/theme monokai

# Переключение режима навигации в стиле текстового редактора Vim
/vim on

# Настройка информации в строке состояния (токены, модель, ветка git)
/statusline detailed

# Установка заголовка терминального окна
/title "Refactoring Auth Module"

# Просмотр списка доступных экспериментальных возможностей
/experimental
```

Управление через флаги CLI и `config.toml`:

```bash
# Просмотр справки по управлению экспериментальными фичами
codex features --help
codex features list
```

В `~/.codex/config.toml`:

```toml
[tui]
theme = "dark"
vim_mode = true
show_token_usage = true
animate_spinner = true

[features]
enable_unstable_streaming = false
```

## Разбор примера

Рассмотрим включение режима Vim и темной темы для комфортной длительной сессии:

1. Запускаем сессию Codex CLI.
2. Вводим `/theme dark`: палитра интерфейса мгновенно переключается на высококонтрастную темную тему.
3. Вводим `/vim on`: поле ввода сообщений начинает поддерживать стандартные режимы Normal/Insert, навигацию клавишами `h, j, k, l` и команды редактирования строк `dd`, `yy`.
4. Вводим `/statusline compact`: строка состояния скрывает лишние системные пути, оставляя только текущую модель и счетчик оставшихся токенов.
5. Настройки сохраняются в профиле и активны при последующих запусках.

## Ограничения и безопасность

- Настройки интерфейса меняют только визуальное представление и клавиатурные сочетания: они **не влияют** на логику генерации кода или уровень безопасности песочницы.
- Экспериментальные функции (`/experimental`) могут содержать нестабильный код и приводить к неожиданным сбоям сессии: не включайте их в критически важных продуктовых пайплайнах.
- Не включайте все доступные флаги экспериментальных возможностей одновременно без изучения документации по каждому из них.

## Типовые ошибки

1. **Случайная активация Vim-режима**: включение `/vim` пользователем, не знакомым с модальным управлением (невозможность выйти из поля ввода или отправить текст).
2. **Использование нестабильных фич в продакшене**: запуск автоматизаций CI с включенными экспериментальными флагами.
3. **Нечитаемые цвета**: выбор темы с низкой контрастностью на неподдерживаемом терминале.

## Практика

1. Протестируйте переключение тем с помощью команды `/theme` в интерактивной сессии.
2. Изучите список экспериментальных функций через команду `/experimental`.
3. Опробуйте включение и отключение режима Vim командой `/vim`.
4. Настройте строку состояния через `/statusline` под ваши предпочтения.
