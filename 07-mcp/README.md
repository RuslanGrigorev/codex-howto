# Инструменты и подключения MCP

Подключить локальный сервер, разобраться в протоколе и диагностировать сетевые интеграции.

В модуле 5 уроков. Каждый урок имеет собственный результат, пример и проверку знаний. Практика с настоящим клиентом отмечена отдельно от автономного разбора.

## Уроки

### 1. [Настоящий локальный MCP через stdio](local-stdio.md)

Запустить учебный stdio-сервер и проверить протокол отдельно от подключения к Codex.

### 2. [MCP-инструменты: список, вызов и ограничения](tools.md)

Понимать, какие действия доступны через сервер, и проверять конкретный вызов.

### 3. [Диагностика MCP: процесс, транспорт и авторизация](diagnostics.md)

Локализовать сбой подключения, не смешивая ошибки запуска и ошибки инструмента.

### 4. [Сетевой MCP, авторизация и официальный Docs MCP](remote.md)

Различать транспорт, авторизацию и права удалённого MCP-сервера.

### 5. [Официальная документация через MCP — необязательное расширение](official-docs.md)

Подключать внешний справочник, не превращая его в обязательную зависимость курса.

## Как проходить

Начните с первого урока или выберите нужную задачу. Раздел «Что нужно перед началом» указывает зависимости. Открывайте подсказку после самостоятельной попытки; отсутствие модели не мешает чтению и разбору, но реальный запуск не засчитывается.
