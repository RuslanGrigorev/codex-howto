# Урок 7: Внешние инструменты без внешней сети (Local Stdio MCP)

## Цель урока
Освоить протокол Model Context Protocol (MCP) в Codex CLI. Научиться запускать и подключать локальный безопасный stdio MCP сервер без обращения к внешней сети, настроить права доступа и выполнять безопасные вызовы инструментов.

## Предпосылки
- Пройдены уроки по основам Codex CLI, безопасности и пользовательским навыкам.
- Базовое понимание формата JSON-RPC 2.0 и работы потоков ввода-вывода (stdin/stdout).

## Что такое Model Context Protocol (MCP)

**Model Context Protocol (MCP)** — это открытый стандартизированный протокол, позволяющий LLM-агентам взаимодействовать с локальными и внешними инструментами, базами данных и источниками контекста.

В отличие от прямых вызовов системных команд через терминал, сервер MCP:
- Явно объявляет схему доступных инструментов (`tools/list`).
- Принимает типизированные аргументы по спецификации JSON Schema.
- Выполняет операции в изолированном контексте.
- Возвращает структурированный ответ (`tools/call`).

### Локальный транспорт Stdio

В соответствии с требованиями автономности курса (OFF-002), основной учебный сценарий использует транспорт **stdio**:

```text
[ Codex CLI ]  --- (stdin: JSON-RPC запрос) --->  [ Локальный Python MCP сервер ]
               <-- (stdout: JSON-RPC ответ) ----
```

Такой сервер:
- Не открывает сетевых сокетов и портов (никакого HTTP/SSE).
- Работает исключительно как дочерний процесс Codex CLI.
- Завершается автоматически вместе с завершением сессии Codex.

### Конфигурация MCP в Codex CLI

В файле конфигурации репозитория `.codex/config.toml` локальный сервер регистрируется в секции `[mcp]`:

```toml
[mcp.servers.local_filesystem]
command = "python"
args = ["scripts/mcp_server.py", "--root", "./workspace"]
read_only = true
```

## Требования безопасности при реализации MCP инструментов

1. **Изоляция каталога (Path Jail):** Инструменты для работы с файлами обязаны проверять, что целевой файл находится строго внутри разрешенного каталога (`workspace_root`), предотвращая выход через `..` (Directory Traversal).
2. **Read-Only по умолчанию:** Инструменты исследования не должны иметь прав на модификацию или удаление данных.
3. **Строгая валидация JSON-RPC:** Каждый запрос обязан содержать корректный `id` и версию `"jsonrpc": "2.0"`.

## Практическое упражнение: `local-mcp`

В этом упражнении вы реализуете безопасный обработчик локального MCP сервера `LocalMcpHandler`, поддерживающий методы:
- `tools/list`: возвращает описание инструмента `read_file_safe`.
- `tools/call`: читает файл в пределах разрешенного каталога. При попытке чтения за пределами рабочей директории возвращает ошибку доступа.
