# Сетевой MCP, авторизация и официальный Docs MCP

## Чему вы научитесь

Различать транспорт, авторизацию и права удалённого MCP-сервера.

## Что нужно перед началом

Сначала пройдите: [Начало: что изучаем и как проверяем результат](../01-start/overview.md). Учебные файлы входят в поставку. Установленные программы и доступ к модели требуются только для соответствующей практики.

Удалённый сервер может требовать сеть и авторизацию. Сначала изучите его назначение, разрешения и владельца; не выдавайте доступ к рабочим аккаунтам для первого учебного примера. Доступ к документации не равен праву выполнять действия от вашего имени.

Необязательное подключение официального сервера документации:

```bash
codex mcp add openaiDeveloperDocs --url https://developers.openai.com/mcp
codex mcp list
```

Локальный курс не зависит от этого подключения. При отсутствии сети используйте встроенный справочник. Не переписывайте урок автоматически только потому, что удалённая страница обновилась.

## Практика

При доступной сети найдите официальное описание `/goal`, сверяйте версию и применимость к CLI. Затем отключите сервер в учебном профиле штатным способом и убедитесь, что чтение курса по-прежнему работает. OAuth, сетевой таймаут и отсутствие инструмента — разные причины ошибки; сохраняйте обезличенную диагностику, не токены.

## Что считается выполнением в Codex

Без модели доступны весь текст, вопросы, исходники и локальные тесты. Они не подтверждают работу CLI. Для практики сохраните версию `codex --version`, модель, провайдера и обезличенный результат реального запуска. Отметку можно внести через `scripts/progress.py` после проверки, согласно [правилам валидации](../reference/validation.md). Самоотчёт ученика не заменяет выпускные доказательства проекта.
