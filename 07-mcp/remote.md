# Сетевой MCP, авторизация и официальный Docs MCP

## Чему вы научитесь

- Подключать удаленные MCP-серверы по протоколам SSE (Server-Sent Events) и HTTP.
- Настраивать заголовки авторизации и токены для защищенных удаленных сервисов.
- Использовать официальный сервер документации `openaiDeveloperDocs` без создания жесткой зависимости курса от внешней сети.
- Безопасно изолировать учетные данные и не допускать утечки токенов в конфигурацию проекта.

## Что нужно перед началом

- Понимание базовой архитектуры Model Context Protocol из урока [Локальный MCP через stdio](local-stdio.md).
- Наличие сетевого подключения (только для тестирования удаленных запросов).
- Установленный Codex CLI 0.160.0.

## Схема процесса

Архитектура сетевого подключения к удаленному MCP-серверу:

```
┌────────────────────────────────────────────────────────┐
│                      Codex CLI                         │
└──────────────────────────┬─────────────────────────────┘
                           │ HTTPS POST / SSE stream
                           │ Заголовок: Authorization: Bearer <TOKEN>
                           ▼
┌────────────────────────────────────────────────────────┐
│             Удаленный MCP-сервер (Remote HTTP)         │
│          https://developers.openai.com/mcp             │
├────────────────────────────────────────────────────────┤
│ 1. Проверка OAuth / Bearer токена                      │
│ 2. Потоковая передача событий SSE (events)             │
│ 3. Обработка запросов tools/call                       │
│ 4. Возврат актуальных сниппетов документации           │
└────────────────────────────────────────────────────────┘
```

Автономный курс не требует внешнего MCP-сервера: локальные файлы курса полностью самодостаточны!

## Команды и параметры

Команды управления удаленными MCP-серверами:

```bash
# Подключение официального сервера документации по URL
codex mcp add openaiDeveloperDocs --url https://developers.openai.com/mcp

# Подключение защищенного сервиса с передачей токена через переменную окружения
codex mcp add secure-service --url https://mcp.internal.corp/sse --header "Authorization=Bearer $CORP_MCP_TOKEN"

# Просмотр статуса сетевых серверов
codex mcp list

# Удаление подключения удаленного сервера
codex mcp remove openaiDeveloperDocs
```

Настройка в `.codex/config.toml`:

```toml
[mcp_servers.remote-docs]
url = "https://developers.openai.com/mcp"
timeout_seconds = 15
```

## Разбор примера

Рассмотрим сценарий поиска актуальных сведений по API через удаленный Docs MCP:

1. Подключаем сервер:
   ```bash
   codex mcp add openaiDeveloperDocs --url https://developers.openai.com/mcp
   ```
2. Проверяем регистрацию через команду `codex mcp list`: сервер отображается как `remote (HTTP/SSE)`.
3. Задаем агенту вопрос: «Каковы актуальные параметры команды `/goal` в Codex CLI?».
4. Агент вызывает удаленный инструмент `search_docs` сервера `openaiDeveloperDocs`.
5. Сервер возвращает официальный фрагмент документации.
6. Если сеть отключена: агент использует встроенные локальные материалы курса без сбоя сессии.

## Ограничения и безопасность

- Никогда не прописывайте секретные API-токены напрямую в файле `.codex/config.toml`, который отслеживается системой Git: передавайте их через переменные окружения (`$MCP_TOKEN`).
- Удаленный сервер имеет доступ к содержимому отправляемых ему аргументов: не передавайте приватный исходный код или личные данные во внешние недоверенные MCP-эндпоинты.
- При отсутствии стабильной сети удаленные вызовы могут завершаться таймаутом (TimeOut): всегда устанавливайте разумный лимит ожидания `timeout_seconds`.

## Типовые ошибки

1. **Коммит токенов в репозиторий**: фиксация токена авторизации в `config.toml` в открытом виде.
2. **Зависимость офлайн-сценариев от сети**: проектирование автоматизаций, падающих при недоступности удаленного сервера документации.
3. **Игнорирование TLS сертификатов**: подключение удаленных серверов по незащищенному протоколу HTTP с передачей учетных данных.

## Практика

1. Подключите официальный сервер `openaiDeveloperDocs` в тестовом окружении (при наличии сетевого подключения).
2. Проверьте статус подключения командой `codex mcp list`.
3. Выполните пробный запрос информации по документации.
4. Отключите сервер командой `codex mcp remove openaiDeveloperDocs` и убедитесь, что локальные справочники продолжают открываться автономно.
