# Официальная документация через MCP — необязательное расширение

## Чему вы научитесь

Подключать внешний справочник, не превращая его в обязательную зависимость курса.

## Что нужно перед началом

Интернет и согласие на настройку подключения. Все основные материалы курса доступны без этого сервиса.

## Как это работает

Документация помогает проверить изменившийся интерфейс, но не должна быть единственным источником текста урока. При недоступном сервере ученик всё равно читает локальный материал и выполняет автономные задания.

Для актуальных возможностей Codex предпочитайте официальные страницы OpenAI. Проверяйте продукт: инструмент `openai` для API — не тот же CLI, что `codex`. Ссылка на документацию без проверки поверхности может привести к инструкции для IDE или desktop вместо терминала.

Заметив отличие, сохраните источник, дату и версию CLI. Не переписывайте учебник автоматически на основании одного ответа поиска.

## Разобранный пример

Необязательное подключение официального сервера документации:

```bash
codex mcp add openaiDeveloperDocs --url https://developers.openai.com/mcp
codex mcp list
```

Перед добавлением проверьте текущий профиль. Настройка не должна молча попадать в личный профиль пользователя из скрипта курса.

## Самостоятельная практика

Найдите официальное объяснение `/goal` и сравните его с локальным уроком. Выпишите одно проверяемое утверждение и источник. Отделите новое в документации от реально проверенного в своей версии.

Затем продолжите читать тот же урок без подключения. Убедитесь, что источник дополняет курс, а не закрывает доступ к его содержимому.

## Ожидаемый результат

Подключение необязательно; локальный урок остаётся достаточным для чтения. Возможные расхождения фиксируются без автоматического объявления совместимости.

## Разбор решения

<details>
<summary>Показать после самостоятельной попытки</summary>

Хорошая запись содержит точную команду, ссылку, дату и статус проверки. Например: «Документация описывает управление целью; в этой среде live-проверка пока не проведена». Наличие ответа MCP не даёт права поставить tested_cli без реального прогона.

</details>

## Типовые ошибки

Требовать MCP для открытия урока; смешивать openai и codex; считать внешний пересказ доказательством работы конкретного релиза.

## Проверка знаний

Ответьте на вопросы внизу страницы. В исходном репозитории они доступны в [файле вопросов](official-docs.quiz.json). Правильные ответы подтверждают понимание; выполнение практики фиксируется отдельно.

## Источники и доступность

Практика требует установленного Codex и доступной выбранной модели. Без модели выполните разбор примера и подготовьте ожидаемый результат; реальный запуск остаётся невыполненным. Целевая версия — 0.160.0. Документальная сверка: 2026-10-05; она не заменяет протокол запуска на вашей ОС.
