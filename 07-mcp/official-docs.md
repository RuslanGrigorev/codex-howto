# Официальная документация через MCP — необязательное расширение

## Чему вы научитесь

- Использовать внешний сервер документации OpenAI через Model Context Protocol как вспомогательный справочник.
- Различать официальные интерфейсы: утилиту `codex` (агентный CLI), утилиту `openai` (API клиент) и плагины для IDE.
- Сопоставлять свежие сведения из документации с локальным базовым срезом версии 0.160.0.
- Сохранять полную работоспособность учебных материалов в изолированной офлайн-среде без внешних MCP.

## Что нужно перед началом

- Понимание механизмов MCP-подключений из предыдущих уроков модуля.
- Наличие подключения к интернету (только при желании протестировать удаленный запрос).
- Установленный Codex CLI 0.160.0.

## Схема процесса

Иерархия источников знаний при работе с материалами курса:

```
┌────────────────────────────────────────────────────────┐
│             Локальный автономный курс                  │
│       (Автономные уроки, схемы, HOWTO-юниты)           │
│        100% доступен офлайн, не требует сети           │
└───────────────────────────┬────────────────────────────┘
                            │ Основной источник
                            ▼
┌────────────────────────────────────────────────────────┐
│             Сверка со срезом версии 0.160.0            │
│       (Фиксация нативного поведения и тестов)          │
└───────────────────────────┬────────────────────────────┘
                            │ Дополнительно (опционально)
                            ▼
┌────────────────────────────────────────────────────────┐
│        Внешний MCP: openaiDeveloperDocs (Remote)       │
│      https://developers.openai.com/mcp                 │
│      - Проверка изменений в новых версиях              │
│      - Справочник параметров и новых slash-команд      │
└────────────────────────────────────────────────────────┘
```

## Команды и параметры

Команды подключения и проверки удаленного сервера документации:

```bash
# Регистрация сервера документации в тестовом профиле
codex mcp add openaiDeveloperDocs --url https://developers.openai.com/mcp

# Просмотр доступных инструментов сервера документации
codex mcp inspect openaiDeveloperDocs

# Запрос информации о параметрах CLI через инструмент поиска документации
codex "Найди в документации описание флага --sandbox-path"

# Удаление внешнего подключения
codex mcp remove openaiDeveloperDocs
```

## Разбор примера

Рассмотрим процесс сопоставления локального урока и обновленной официальной документации:

1. Подключаем сервер документации:
   ```bash
   codex mcp add openaiDeveloperDocs --url https://developers.openai.com/mcp
   ```
2. Выполняем поиск по теме `/goal`:
   - Агент запрашивает инструмент `search_docs(query="codex cli /goal command")`.
   - Сервер возвращает страницу документации: «В версии 0.160.0 команда `/goal` поддерживает флаги `--auto` и параметры чекпоинтов».
3. Сопоставляем полученный ответ с уроком [Планирование и реализация через /goal](../02-workflow/plan-goal.md).
4. Убеждаемся, что описание полностью согласуется с локальным материалом.
5. Отключаем внешний сервер и проверяем, что локальный урок открывается без сетевых ошибок.

## Ограничения и безопасность

- Внешний сервер `openaiDeveloperDocs` не является обязательным компонентом: курс спроектирован для полностью автономного прохождения.
- Не путайте утилиту `openai` (официальный CLI для прямого взаимодействия с OpenAI REST API) и `codex` (агентный CLI для разработки со встроенной песочницей и TUI).
- Обновление удаленной документации не означает автоматического изменения поведения уже установленного локального бинарника Codex CLI 0.160.0.

## Типовые ошибки

1. **Блокировка обучения из-за сети**: отказ от прохождения уроков при недоступности удаленного сервера документации.
2. **Смешение продуктов**: применение документации по Desktop-приложению или расширению для VS Code к консольному клиенту Codex CLI.
3. **Слепое принятие изменений**: объявление совместимости с новыми недокументированными флагами без реального тестирования в терминале.

## Практика

1. Подключите сервер `openaiDeveloperDocs` в отдельном учебном профиле (при наличии доступа к сети).
2. Запросите у модели описание синтаксиса команды `/permissions`.
3. Сравните полученный результат с описанием в локальном уроке курса.
4. Отключите сервер и подтвердите, что локальные тесты и упражнения продолжают выполняться автономно.
