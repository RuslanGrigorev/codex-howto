# Работа над курсом

Сначала прочитайте `AGENTS.md` и `reference/validation.md`. Редактируйте исходные Markdown/JSON и код, а не результат сборки в `.learning/site`. Один источник структуры — `course.json`; источники и применимость — `sources.json`. Не добавляйте сервер или систему провайдеров ради статического учебника.

## Небольшое изменение

До правки добавьте воспроизводимый отрицательный пример. Исправьте реализацию, обновите текст и quiz одновременно, увеличьте `revision` изменённого урока. Сохраните `lesson_id`, если смысл урока остаётся тем же. Проверки должны вызывать настоящий производственный код, а не локальную имитацию нужного условия.

```bash
python scripts/check_project.py catalog
python -m pytest -q scripts/tests
python scripts/verify.py --profile offline
```

Зависимости устанавливаются до автономного прогона. Отсутствие Playwright, Chromium или Codex — явная блокировка соответствующего этапа, не причина подставить успешный результат. CI обычного PR не получает ключей модели и не публикует релиз автоматически.

## Новый релиз Codex

Получите наблюдение `scripts/check_updates.py --fetch --output .learning/upstream.json`, сохраните исходную версию и сравните команды, схему и страницы. Полный baseline меняйте только после проверки происхождения снимка. Нельзя просто подменить `target_cli` или `tested_cli` и объявить материалы совместимыми. Дополните матрицу покрытия и повторите затронутые реальные сценарии.

Внешние ссылки служат источниками, а не обязательной частью автономного урока. Не вставляйте тексты сайтов целиком и не добавляйте чужие изображения без проверки лицензии. Удаление учебных следов другого клиента не должно удалять MIT LICENSE и историческую атрибуцию.
