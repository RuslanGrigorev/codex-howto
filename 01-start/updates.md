# Версии, обновление и возврат к проверенной установке

## Чему вы научитесь

Обновлять CLI осознанно и сохранять возможность повторить учебный сценарий на прежней версии.

## Что нужно перед началом

Рабочая установка Codex. Интернет требуется только для получения новой версии; изучение порядка действий доступно локально.

## Как это работает

Версия курса и версия CLI — разные номера. Курс может поддерживать определённый релиз, а установленный клиент быть новее. Фраза «последняя версия» не помогает воспроизвести ошибку: фиксируйте полный номер.

Не смешивайте способы установки без причины. После обновления проверьте, что запускается именно новый бинарный файл. Если пакет установлен менеджером пакетов, обновление и возврат выполняют тем же способом. Команда `codex update` применяется только там, где текущая установка поддерживает самостоятельное обновление.

Перед экспериментом сохраните пользовательскую конфигурацию вне публичного репозитория. Учётные данные не добавляйте в Git. Обновление курса не должно молча переписывать ваш профиль или прогресс.

## Разобранный пример

Без изменений системы можно получить исходные сведения:

```bash
codex --version
codex --help
```

Сопоставьте номер с `target_cli` в `sources.json`. Для установки через npm целевая версия выбирается явно, например `@openai/codex@0.160.0`; саму установку выполняют отдельно с доступом к сети. Установка произвольного номера без проверки существования релиза недопустима.

## Самостоятельная практика

Запишите текущую версию и способ установки. Выберите один знакомый сценарий: открытие `/status`, чтение учебного файла, завершение задачи. Сохраните его результат как исходную точку.

Составьте план обновления и возврата: откуда берётся пакет, как проверяется версия, где сохранены настройки, какой сценарий повторяется. На основной рабочей установке обновление не является обязательным действием этого урока.

## Ожидаемый результат

Есть воспроизводимый план и исходный номер версии. Совпадение номера не выдано за проверку всех функций.

<details>
<summary>Показать после самостоятельной попытки</summary>

Хороший план заканчивается повторным запуском того же сценария в той же папке. При различии результата сначала сравнивают `--help`, профиль и доступную модель, затем релизные изменения. Прогресс курса сохраняют отдельным JSON. Не удаляют домашний каталог Codex ради устранения одного предупреждения.

</details>

## Типовые ошибки

Записывать только «latest»; обновлять несколько компонентов одновременно; считать успешную установку подтверждением совместимости; публиковать резервную копию авторизации.

## Проверка знаний

Ответьте на вопросы внизу страницы. В исходном репозитории они доступны в [файле вопросов](updates.quiz.json). Правильные ответы подтверждают понимание; выполнение практики фиксируется отдельно.

## Источники и доступность

Материалы и письменная часть доступны без сети. Установку зависимостей и сетевые действия выполняют отдельно, когда доступна сеть. Целевая версия — 0.160.0. Документальная сверка: 2026-10-05; она не заменяет протокол запуска на вашей ОС.
