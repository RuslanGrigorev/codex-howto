# Начало: что изучаем и как проверяем результат

## Чему вы научитесь

Выбрать маршрут обучения и отличать чтение, проверку знаний, упражнение и реальный запуск Codex.

## Что нужно перед началом

Учебные файлы входят в поставку. Установленные программы и доступ к модели требуются только для соответствующей практики.

Этот практикум посвящён терминальному клиенту **`codex`**, а не инструменту `openai` для вызовов API. Русские тексты курса и ответы нашего наставника не означают перевода всех меню самого клиента. Команды, имена файлов и ключи настроек остаются в оригинале.

Есть три независимых результата: прочитанный урок, понимание по тесту и выполненная практика. Чтение не закрывает тест. Для некоторых тем дополнительно требуется реальный запуск модели; недоступность сети не превращает его в успешный.

Готовый пакет открывается файлом `index.html`. Исходники упражнений находятся в `source/examples`, справочник — в разделе «Справочник». Для чтения и тестов нужен только современный браузер; для Python-упражнений — заранее установленный Python 3.11 или новее. Git и Codex нужны для соответствующих практик. Сам Python и модели не включены в поставку.

## Первая проверка

```bash
python --version
git --version
codex --version
codex --help
```

Отсутствующую программу отметьте как неподготовленную зависимость, не скачивайте ничего неожиданно во время офлайн-урока. Откройте [справочник команд](../reference/commands.md), найдите различие между `codex` и `codex exec`, затем ответьте на вопрос внизу страницы.

## Наставник и самостоятельный маршрут

В корне курса запустите Codex и укажите `$learn`. Это навык **этого репозитория**, не встроенная slash-команда. Без модели читайте объяснение, выполняйте действия самостоятельно, используйте подсказки и эталоны. Экспортируйте прогресс перед переносом ZIP или сменой браузера: хранилище `file://` зависит от браузера и пути к файлу.
