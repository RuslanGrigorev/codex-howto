# Установка, обновление и платформы

## Чему вы научитесь

Подготовить подходящую установку Codex и проверить её версию до начала практики.

## Что нужно перед началом

Сначала пройдите: [Начало: что изучаем и как проверяем результат](overview.md). Учебные файлы входят в поставку. Установленные программы и доступ к модели требуются только для соответствующей практики.

Сначала выберите ОС, архитектуру и способ установки. При наличии Node.js один из официальных способов — npm. Следующие действия требуют сети и выполняются **до** автономного обучения:

```bash
npm install -g @openai/codex@0.160.0
codex --version
```

Не подставляйте `latest` в воспроизводимую учебную среду: он со временем меняется. Альтернатива — заранее получить исполняемый файл для своей платформы из официального релиза. Не переносите Linux-бинарник в Windows и не считайте WSL идентичным нативной Windows. Сохраните установщик и сведения о происхождении вне репозитория, без секретов.

Перед обновлением экспортируйте учебный прогресс и сохраните предыдущую версию инструмента. Обновление курса не должно само запускать npm или менять глобальную конфигурацию. Удаление npm-установки выполняется `npm uninstall -g @openai/codex`; оно не означает удаление пользовательской истории или учётных данных.

## Практика

Составьте паспорт среды: ОС, архитектура, Python, Git, версия Codex и способ установки. Выполните `codex --help` из новой оболочки. Если команда не найдена, проверьте PATH и каталог установки; не отключайте защиту ОС ради устранения ошибки. Решение считается найденным, когда запускается именно выбранная версия, а не случайная вторая копия.
