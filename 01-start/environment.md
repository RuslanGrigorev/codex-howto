# Подготовка среды: терминал, Python и Git

## Чему вы научитесь

Проверять необходимые программы и отличать оболочку, Codex и браузерный учебник.

## Что нужно перед началом

Распакованный курс и терминал. Для локальных упражнений нужен Python 3.11 или новее; Git используется в уроках о версиях файлов.

## Как это работает

Курс состоит из трёх независимых частей. HTML-страницы открывает браузер. Упражнения проверяет Python. Интерактивные запросы выполняет Codex. Ошибка одной части не означает поломку всех остальных.

Команды оболочки вводятся в терминале. Встроенные `/goal` и `/plan` — в поле ввода Codex. `$learn` вызывает навык курса. Не вставляйте строку из чужого терминала вместе с приглашением `>` или `$`: это обозначения, а не часть команды.

Выберите одну среду для всей первой практики. Смешение Windows Python, WSL Git и разных каталогов усложняет диагностику. Сначала выясните, какой исполняемый файл запускается и какой каталог является текущим.

## Разобранный пример

В терминале из корня исходников выполните:

```bash
python --version
git --version
codex --version
python -c "from pathlib import Path; print(Path.cwd()); print(Path('course.json').is_file())"
```

Последняя строка должна вывести путь к распакованным исходникам и `True`. В готовом учебном ZIP сначала перейдите в `source`. Если используется команда `python3`, заменяйте ею `python` последовательно.

## Самостоятельная практика

Составьте `environment.txt` со сведениями о системе, версиях трёх программ и каталоге курса. Записывайте только версии и пути без имени пользователя, когда собираетесь публиковать файл. Не устанавливайте отсутствующий пакет наугад: сначала определите, какая часть курса его требует.

Откройте вводный урок в браузере, затем вызовите `python scripts/verify.py --prepare small-fix` из исходников. Это разные действия; подготовка не обязана открывать браузер.

## Ожидаемый результат

Вы можете указать, где запускается каждая команда. Проверка `course.json` возвращает `True`, а подготовка создаёт отдельную рабочую папку без изменения эталона.

## Типовые ошибки

Выполнение `/goal` в Bash; запуск проверок из каталога сайта вместо `source`; установка пакетов без понимания ошибки; публикация полного домашнего пути.
