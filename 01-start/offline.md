# Автономное обучение и локальная модель

## Чему вы научитесь

Научитесь организовывать полностью автономный (offline) процесс обучения работе с Codex CLI 0.160.0 без подключения к интернету, понимать состав автономного пакета поставки, работать с локальным поисковым индексом и квизами через протокол `file://`, сохранять и переносить прогресс в JSON-файлах, а также настраивать подключение к локальным Open-Source моделям через провайдер Ollama или vLLM.

## Что нужно перед началом

1. Распакованный ZIP-пакет курса или локальный клон репозитория.
2. Веб-браузер с поддержкой современных стандартов JavaScript и локального хранилища.
3. Локальный интерпретатор Python 3.11+ для автономного запуска тестов упражнений.
4. Дополнительно (для интерактивной генерации): локально запущенный сервис моделей (например, Ollama на `http://127.0.0.1:11434`).

               │                              │
┌──────────────▼──────────────────────────────▼───────────────┐
│ Локальное хранение состояния                                │
│ - Браузер: localStorage (прочитано, квизы)                  │

## Команды и параметры

Команды работы с автономным пакетом и локальными моделями:

```bash
# Сборка автономного статического сайта курса
python scripts/build_website.py --output .learning/site

# Проверка локальных ссылок сайта без обращения в сеть
python scripts/check_site.py --site .learning/site

# Запуск Codex CLI с подключением к локальному OSS-провайдеру
codex --oss --local-provider ollama

# Указание конкретного адреса локального API
codex -c local_endpoint="http://127.0.0.1:11434"

# Запуск проверки упражнения в автономном режиме
python scripts/verify.py --exercise small-fix --workspace .learning/workspaces/small-fix
```

## Разбор примера

Рассмотрим разницу между внешними сетевыми сервисами и локальным loopback-провайдером:

1. **Внешний облачный провайдер**: требует отправки кода и промптов через интернет на серверы OpenAI/ChatGPT, валидного API-ключа и постоянного интернет-соединения.
2. **Локальный OSS-провайдер (Ollama / vLLM)**: запускается на вашем собственном компьютере на адресе `http://127.0.0.1:11434`. Codex CLI обращается к локальному сокету через loopback-интерфейс ядра ОС. Ни один байт кода или запросов не покидает вашу машину.

Пример конфигурации `config.toml` для полностью изолированной среды:
```toml
sandbox_mode = "workspace-write"
approval_policy = "untrusted"
web_search = false
model = "llama3:latest"
```

## Ограничения и безопасность

1. **Автономность материалов**: пакет курса гарантированно работает без сети. Все 12 архитектурных схем поставляются как локальные валидные SVG без CDN и без внешних шрифтов.
2. **Локальные модели и качество инструментов**: компактные локальные модели (7B–14B параметров) могут хуже следовать строгим инструкциям вызова инструментов (tool calling) и чаще допускать синтаксические ошибки в diff по сравнению с флагманскими облачными моделями.
3. **Отсутствие фоновой синхронизации**: браузер (через `file://`) не имеет права напрямую записывать файлы на диск вашей ОС. Поэтому синхронизация между браузерным прогрессом и `.learning/progress.json` выполняется вручную через экспорт/импорт JSON.

## Ошибки и диагностика

| Симптом | Причина | Способ диагностики и решения |
|---|---|---|
| Поиск по сайту не находит результаты в браузере | В браузере отключён JavaScript или файл `search-index.js` не загружен. | Убедитесь, что JavaScript включён, и открывайте страницы через современный браузер. |
| `Connection refused: 127.0.0.1:11434` при `--oss` | Сервис Ollama не запущен или слушает другой порт. | Запустите Ollama в отдельном терминале: `ollama serve` и проверьте `curl http://127.0.0.1:11434`. |
| Прогресс квизов пропал после перезапуска браузера | Браузер настроен на режим инкогнито или очищает данные сайтов при закрытии. | Регулярно нажимайте «Экспорт прогресса» в панели управления курсом. |

## Практика

1. Распакуйте учебный пакет в отдельный каталог.
2. Отключите интернет (или сетевой адаптер) и откройте `index.html` в браузере.
3. Воспользуйтесь полем поиска в верхней панели и найдите тему «песочница».
4. Ответьте на вопросы проверочного квиза внизу этой страницы и нажмите кнопку «Экспорт прогресса» для сохранения файла `codex-course-progress.json`.

<details>
<summary>Подсказка к заданию</summary>

Кнопка «Экспорт прогресса» создаёт файл JSON, содержащий хэши уроков, статус прочтения, набранные баллы за квизы и список выполненных локальных упражнений. Этот файл можно перенести на любой другой компьютер или восстановить в другом браузере через кнопку «Импорт прогресса».

</details>

## Самопроверка

Критерии завершения:
1. Вы проверили, что статический сайт, поиск и схемы SVG открываются и функционируют без подключения к интернету.
2. Вы умеете экспортировать и импортировать файл прогресса обучения.
3. Вы понимаете, как подключается локальный провайдер моделей через аргумент `--oss`.

<details>
<summary>Контрольные вопросы для самопроверки</summary>

- **Вопрос**: Требует ли проверка упражнений через `python scripts/verify.py` доступа к интернету?
- **Ответ**: Нет, все тесты упражнений полностью автономны и проверяют Python-код локально без обращения к сети.
- **Вопрос**: Почему браузер не сохраняет автоматически статус прохождения упражнения при вызове `verify.py`?
- **Ответ**: В целях безопасности браузерные песочницы изолируют локальные файлы `file://` от прямого доступа к файловой системе ОС.

</details>
