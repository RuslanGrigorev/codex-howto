# Автономное обучение и локальная модель

## Чему вы научитесь

Подготовить автономный пакет и понимать, какие действия требуют заранее доступной модели.

## Что нужно перед началом

Сначала пройдите: [Начало: что изучаем и как проверяем результат](overview.md). Учебные файлы входят в поставку. Установленные программы и доступ к модели требуются только для соответствующей практики.

Офлайн-поставка содержит текст, поиск, проверки знаний, исходники, подсказки, эталоны и тесты. Она не содержит Python, Git, Codex, модельные веса или вашу авторизацию. Эти зависимости готовятся заранее. В обязательных локальных упражнениях нет установки библиотек через сеть.

Сам учебник не обращается к внешним сайтам автоматически. Ссылки на официальные источники — необязательное средство сверки при наличии сети. Поиск использует локальный индекс. Результаты браузера экспортируются в JSON; результаты Python импортируются из `.learning/progress.json`. Автоматической синхронизации браузера и диска нет.

Для живого наставника без внешней сети нужен подготовленный локальный провайдер и уже загруженная модель. В Codex предусмотрены `--oss` и выбор провайдера, например:

```bash
codex --oss --local-provider ollama
```

Это не команда скачивания модели и не гарантия поддержки всех функций конкретной моделью. Локальный сервис должен быть уже доступен. Проверяйте качество работы и поддержку инструментов отдельно. Loopback-соединение с локальным сервисом отличается от доступа к Интернету.

## Практика

Отключите внешний доступ, распакуйте курс в новый каталог и найдите `/goal` поиском. Пройдите тест, экспортируйте прогресс, сбросьте его и импортируйте обратно. Затем запустите подготовленное Python-упражнение. Не засчитывайте чтение записанного диалога как реальный запуск CLI.
