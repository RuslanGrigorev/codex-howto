# Project Context

## Purpose
Автономный русскоязычный учебный курс и интерактивный справочник по Codex CLI, адаптированный из форка claude-howto. Проект позволяет изучать работу с Codex CLI полностью офлайн (через статический локальный сайт и самостоятельные упражнения), а также содержит локального наставника (`$learn`) и проверяемую систему прогресса. Архитектура курса проектируется расширяемой для добавления английской локализации (RU/EN).

## Tech Stack
- Python 3.11+ (стандартная библиотека, Jinja2, Markdown, Pygments, pytest)
- Vanilla HTML / CSS / JavaScript (без фреймворков и без внешних runtime CDN; поддержка запуска по `file://`)
- OpenSpec 1.14+ (спецификации и управление изменениями)
- Целевой CLI: Codex CLI 0.160.0

## Project Conventions

### Code Style
- Python: PEP 8, типизация, минимальные внешние зависимости для рантайма обучающегося (предпочтение stdlib для учебных проверок).
- Frontend: строгий семантический HTML5, чистый CSS без тяжелых сборщиков в рантайме, экранирование данных и безопасность `file://`.
- Контент: технические команды, пути и флаги сохраняют оригинальный синтаксис; пояснительный текст, задания, тесты и UI локализуются.

### Architecture Patterns
- **Single Source of Truth**: единый `course.json` определяет модули, уроки, зависимости и ревизии.
- **Масштабируемая локализация (i18n)**: структура словарей интерфейса `locales/ui.<lang>.json` (по умолчанию `ru`, с возможностью подключения `en`), разделение языковых файлов уроков.
- **Офлайн по умолчанию**: работа всех материалов без доступа к сети.
- **Детерминированная валидация**: скрипт `scripts/verify.py` с профилями (`offline`, `live`, `release`) и изолированным режимом проверки упражнений (`--exercise`).

### Important Constraints & Safety Rules
- **Строгая изоляция пользовательской среды**: категорически запрещено изменять или перезаписывать глобальные пользовательские конфигурации (`~/.codex/`, `~/.agents/`, конфиги Codex Desktop, а также кастомные CLI-алиасы/провайдеры, такие как Codex-MiniMax).
- Все учебные конфигурации, навыки (`.agents/skills/learn/`), временные тестовые запуски и упражнения изолированы исключительно внутри рабочего каталога репозитория/проекта.
- Проверки упражнений не имеют права выходить за пределы изолированных рабочих каталогов (`..` и symlinks запрещены).
