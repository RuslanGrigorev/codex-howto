## Context

Существующий каталог, формат прогресса и учебный skill остаются основой. Патч рассчитан на последний пользовательский архив; старый патч до него применять не нужно.

## Goals / Non-Goals

Цели: устранить битые ссылки и одноурочные модули, вернуть русское оформление, сделать отсутствие проверок видимым. Не цели: собственный AI-клиент, серверная синхронизация, автоматический перевод новой документации, объявление полного покрытия по числу страниц.

## Decisions

1. Источники решений копируются без изменения в source/, экранированные представления — в materials/. Подсказки представлены читаемым Markdown с раскрываемыми разделами.
2. Сборка идёт во временный каталог и заменяет предыдущую только после проверки всех локальных ссылок. Отсутствие цели — ошибка, не ссылка на GitHub.
3. Идентификаторы прогресса сохраняются; редакции уроков увеличиваются. Миграция не засчитывает ранее отсутствующую практику.
4. sources.json хранит темы, состояние редакционного ревью и открытые вопросы. Структурная связность не выдаётся за полноту документации.
5. Обязательный file:// прогон отделён от дополнительного DOM-прогона. Заблокированная среда не считается успешным прохождением.

## Risks / Trade-offs

Расширение курса повышает объём редакторской проверки. Часть онлайн-документации новее целевого тега: такие сведения отмечаются и требуют нативной сверки. Python-проверки не являются системной песочницей для недоверенного кода.

## Migration Plan

Проверка исходных хешей → резервная копия → накопительный патч → проверка всего ожидаемого дерева → локальные тесты → file:// и реальные сценарии Codex → ручное ревью и выпуск. При конфликте агент не использует принудительное перезаписывание.
