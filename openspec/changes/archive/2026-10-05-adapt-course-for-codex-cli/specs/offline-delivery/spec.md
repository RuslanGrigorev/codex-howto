# Автономная поставка

## Purpose

Позволяет проходить учебные материалы и самостоятельную практику из готового локального архива без внешней сети и без сборки на компьютере ученика.

## ADDED Requirements

### Requirement: OFF-001 — Открытие готового курса без сети

Готовый пакет SHALL открываться через file:// с index.html без установки сервера. Обязательные страницы, стили, скрипты, данные и изображения SHALL использовать локальные относительные пути; курс SHALL NOT автоматически обращаться к внешней сети.

#### Scenario: OFF-001-S01 — Холодный автономный запуск
- **GIVEN** ZIP распакован в каталог с пробелами и кириллицей; браузер имеет новый профиль и заблокированную внешнюю сеть
- **WHEN** ученик открывает index.html и посещает все обязательные страницы
- **THEN** все страницы и ресурсы доступны, ошибок загрузки нет, ни одной попытки внешнего запроса не зарегистрировано

#### Scenario: OFF-001-S02 — Внедрённая внешняя зависимость
- **GIVEN** в тестовую копию добавлена загрузка скрипта или изображения по HTTPS
- **WHEN** выполняется проверка автономной поставки
- **THEN** проверка завершается FAIL и указывает страницу и внешний адрес, даже если ресурс был бы доступен из кеша

### Requirement: OFF-002 — Полнота локального комплекта

Пакет SHALL содержать все обязательные уроки, локальный справочник, задания, исходники упражнений, подсказки, решения и средства проверки. Ссылки на официальный сайт SHALL быть дополнительными источниками, а не обязательными шагами обучения.

#### Scenario: OFF-002-S01 — Прохождение без внешней документации
- **GIVEN** внешняя сеть отключена и содержимое браузерного кеша отсутствует
- **WHEN** ученик проходит десять модулей самостоятельного маршрута
- **THEN** для каждого обязательного действия достаточно файлов пакета; ссылки на исходники открывают локальные файлы или их локальные представления

#### Scenario: OFF-002-S02 — Пропавшее решение или исходник
- **GIVEN** из копии пакета удалён один файл обязательного упражнения
- **WHEN** выполняется проверка комплекта по каталогу курса
- **THEN** выпуск блокируется с ID урока и отсутствующим путём

### Requirement: OFF-003 — Явные предварительные зависимости

Чтение курса SHALL требовать только браузер. Исполняемая самостоятельная практика SHALL использовать заранее установленный Python 3.11+ и, где заявлено, Git. Проверки SHALL NOT устанавливать зависимости, скачивать репозитории или требовать учётную запись; отсутствие инструмента SHALL давать понятное сообщение.

#### Scenario: OFF-003-S01 — Подготовленная машина без сети
- **GIVEN** Python и Git установлены заранее; менеджеры пакетов не имеют доступа к сети
- **WHEN** запускаются все самостоятельные упражнения
- **THEN** проверки выполняются без pip install, npm install и скачивания дополнительных материалов

#### Scenario: OFF-003-S02 — Не установлен необходимый инструмент
- **GIVEN** в тестовом PATH отсутствует Git либо ученик не может запустить Python
- **WHEN** ученик открывает раздел подготовки или запускает доступную предварительную проверку
- **THEN** указано, какой инструмент нужен и как подготовить его заранее; чтение, вопросы и разбор решения остаются доступны; практический запуск не засчитывается

### Requirement: OFF-004 — Честное разделение режимов обучения

Курс SHALL различать самостоятельное обучение без модели, живую работу Codex с сетевым провайдером и дополнительный запуск с заранее подготовленной локальной моделью. Отсутствие модели SHALL NOT закрывать учебник; записанный диалог SHALL NOT засчитываться как реальный запуск Codex.

#### Scenario: OFF-004-S01 — Нет Codex и модели
- **GIVEN** ученик располагает только пакетом, браузером и инструментами самостоятельных упражнений
- **WHEN** он проходит маршрут без наставника
- **THEN** доступны объяснения, тесты, локальные упражнения, подсказки и решения; отдельная отметка практики Codex остаётся неподтверждённой

#### Scenario: OFF-004-S02 — Локальный провайдер недоступен
- **GIVEN** выбран дополнительный локальный режим, но локальный сервер модели не запущен
- **WHEN** ученик использует инструкцию проверки готовности
- **THEN** получает указание подготовить модель заранее; курс не скачивает модель и не переключается молча на облачный провайдер

### Requirement: OFF-005 — Работа при ограничениях браузера

Курс SHALL сохранять доступ к тексту при отключённом JavaScript. При отказе clipboard или localStorage интерфейс SHALL сообщать об ограничении и предоставлять ручное копирование либо экспорт прогресса без потери текущего состояния в памяти страницы.

#### Scenario: OFF-005-S01 — Отключены удобства браузера
- **GIVEN** clipboard и localStorage выбрасывают исключения
- **WHEN** ученик копирует команду и сохраняет прогресс
- **THEN** команду можно выделить вручную, текущий прогресс можно экспортировать, ошибки не ломают страницу

#### Scenario: OFF-005-S02 — Отключён JavaScript
- **GIVEN** браузер не выполняет скрипты
- **WHEN** ученик открывает урок
- **THEN** текст, навигация и решения читаются; сообщение noscript по-русски объясняет недоступность интерактивных тестов и прогресса

### Requirement: OFF-006 — Проверяемая и безопасная упаковка

ZIP курса SHALL иметь список файлов с SHA-256, версию курса и заявленную совместимость. Он SHALL NOT включать секреты, личные результаты, журналы сессий, абсолютные файловые пути или файловые ссылки за пределы пакета. Уведомления об авторстве заимствованных материалов SHALL сохраняться.

#### Scenario: OFF-006-S01 — Повторная сборка
- **GIVEN** зафиксированы исходники и зависимости сборки
- **WHEN** выполняются две сборки и сверяются манифесты
- **THEN** содержимое поставки совпадает по хешам, за исключением явно исключённых технических метаданных времени; отсутствуют личные данные

#### Scenario: OFF-006-S02 — Секрет или небезопасный путь
- **GIVEN** в тестовую сборку добавлен .env, .learning/progress.json либо ссылка на внешний файл
- **WHEN** выполняется упаковка
- **THEN** выпуск завершается FAIL с безопасной диагностикой без вывода значения секрета
