# Официальные источники и границы проверки

Дата чтения источников: **4 октября 2026 года**. Использованы первичные официальные материалы Fission-AI и OpenAI. URL могут перенаправляться; для курса требуется проверять конечный адрес и применимость к CLI, а не только домен.

## Реестр для этой спецификации

### OS-01 — OpenSpec — репозиторий и основной формат
Источник: [OpenSpec — репозиторий и основной формат](https://github.com/Fission-AI/OpenSpec/).
Использование: Структура change, принятие решения до реализации; не отдельная платформа разработки.

### OS-02 — OpenSpec — схема spec-driven
Источник: [OpenSpec — схема spec-driven](https://raw.githubusercontent.com/Fission-AI/OpenSpec/main/schemas/spec-driven/schema.yaml).
Использование: proposal, specs, design, tasks; Requirement/Scenario, Purpose, SHALL/MUST; сценарии WHEN/THEN и проверяемые задачи.

### OS-03 — OpenSpec — CLI
Источник: [OpenSpec — CLI](https://raw.githubusercontent.com/Fission-AI/OpenSpec/main/docs/cli.md).
Использование: init --tools codex, validate --strict --json --no-interactive; проверка структуры не исполняет приложение.

### OS-04 — OpenSpec — русский текст и язык структуры
Источник: [OpenSpec — русский текст и язык структуры](https://raw.githubusercontent.com/Fission-AI/OpenSpec/main/docs/multi-language.md).
Использование: config.yaml с русским context; структурные заголовки и нормативные слова остаются английскими.

### OS-05 — OpenSpec — интеграция Codex
Источник: [OpenSpec — интеграция Codex](https://raw.githubusercontent.com/Fission-AI/OpenSpec/main/docs/supported-tools.md).
Использование: Codex использует .agents/skills и форму $openspec-...; apply соответствует openspec-apply-change.

### OS-06 — OpenSpec — целевой выпуск инструмента
Источник: [OpenSpec — целевой выпуск инструмента](https://github.com/Fission-AI/OpenSpec/releases/tag/v1.14.0).
Использование: Версия 1.14.0 выбрана для воспроизводимой проверки формата. Инструмент в текущем runtime не установлен.

### CX-01 — Codex — выпуск-кандидат

## Как превратить источники в автономный курс

Не делать зеркало всех сайтов и не требовать их чтения от ученика. Автор готовит собственный достаточный русский справочник по используемым функциям, с исходными командами, областью применимости и ссылками на источник. Реестр хранит дату проверки и связи с уроками. Для обновления достаточно хеша/версии документа, локальной справки CLI и короткого решения сопровождающего по изменению.

Внешние источники в текущем пакете обосновывают выбор формата и направлений адаптации. Они не являются доказательствами выполнения продуктовых требований. Команды и конфигурации каждого нового урока проверяются отдельно на целевой версии до публикации.

Первоначально target_cli = 0.160.0, tested_cli = null. Веб-проверка существования релиза не заменяет codex --version в журнале реального испытания. Точная модель, версии браузеров и рабочий набор зависимостей записываются при подготовке исполняемого baseline, а не выдумываются в спецификации.

Текущие источники OpenAI часть путей переносят с developers.openai.com на learn.chatgpt.com/docs. Скрипт обновления не должен считать смену пути или оформления страницы автоматическим изменением поведения CLI.

Полный пакет курса не должен распространять сторонние установщики, модельные веса и шрифты как скрытые зависимости. Собственные пояснения предпочтительнее копирования целых страниц; уведомления об авторстве заимствованных файлов сохраняются.

## Что не использовано как источник истины

Посты пользователей, обзоры и аналогии с Claude не используются для утверждений о синтаксисе Codex. Предыдущие обсуждения проекта определяют намерение пользователя, но не заменяют официальную документацию и испытание бинарника.
