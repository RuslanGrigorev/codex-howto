# Решение по исходному проекту

## Выбор

**Дорабатываем исходный проект в отдельном форке; не создаём новую реализацию.** Новые название и содержание не требуют нового frontend или собственного приложения для терминала. Форк не предполагает обязательной регулярной синхронизации с дальнейшим развитием Claude How-To: полезные изменения можно переносить точечно.

## Убираем из активной поставки

Claude-брендинг, его исполняемые конфиги и install-инструкции, неподдерживаемые языковые деревья, старые демонстрации терминала, второй трекер, сетевые обязательные практики, автопубликацию/деплой и опасные разрешения по умолчанию. Историю и атрибуцию не маскируем.

EPUB, промоматериалы и публикацию собственного плагина откладываем. Сведения об IDE/desktop/cloud не становятся обязательными модулями. Поддержка другого AI-клиента в будущем — отдельное изменение OpenSpec, без заранее построенного слоя абстракции.

## Первая проверяемая вертикаль

Один урок `workflow.small-fix`: русский HTML → самостоятельное исправление в изолированном Python-примере → эталон и минимум одна ошибочная мутация → локальная проверка → сохранение/экспорт прогресса → `$learn` на тех же материалах → реальный live-прогон. Следующие модули копируют этот проверенный формат, а не новый стек.
