# Как проверять курс после нового релиза Codex

## Чему вы научитесь

Находить затронутые темы и повторять проверки без автоматического переписывания учебника.

## Что нужно перед началом

Локальный курс, sources.json и понимание различия документальной и живой проверки.

## Как это работает

Обновление начинается с наблюдения: что изменилось в командах, конфигурации или документации. Сравнение должно связывать новый пункт с конкретным уроком или разделом справочника.

Если исходный снимок неполон, результат сравнения тоже неполон. Нельзя объявить совместимость неизвестной версии лишь потому, что скрипт не нашёл знакомого изменения. Новый пункт документации требует разбора применимости.

Обновлятор курса не устанавливает CLI и не редактирует статьи автоматически. Он готовит перечень для проверки. Человек уточняет содержание, затем повторяются автоматические, браузерные и живые сценарии нужной области.

## Разобранный пример

Локальная проверка без сетевых действий:

```bash
python scripts/check_updates.py
python scripts/check_coverage.py
```

Отсутствие подготовленного кандидата обновления даёт INCOMPLETE, а не COMPATIBLE. Сетевой сбор включается только явно и сохраняется в отдельный файл.

## Самостоятельная практика

Разберите воображаемое изменение: появился новый вариант `/goal`. Найдите связанные уроки и вопросы. Укажите, какой пример, справочник и проверку потребуется обновить.

Затем повторите задачу для изменившегося ключа конфигурации. Не редактируйте tested_cli, пока не появился реальный протокол.

## Ожидаемый результат

Изменение связано с материалами и проверками; неполная информация не выдана за подтверждённую совместимость.

Для нового поведения цели затрагиваются урок установки цели, управление, справочник slash-команд, вопросы и LIVE-GOAL. Для ключа настроек — пример TOML, локальный справочник и проверка строгой конфигурации. Общий интерфейс сайта не нужно переписывать без отдельной причины.

</details>

## Типовые ошибки

Автоматически обновлять все уроки; повышать tested_cli по номеру релиза; скрывать неизвестные темы; считать изменение HTML доказательством изменения продукта.

## Проверка знаний

Ответьте на вопросы внизу страницы. В исходном репозитории они доступны в [файле вопросов](maintenance.quiz.json). Правильные ответы подтверждают понимание; выполнение практики фиксируется отдельно.

## Источники и доступность

Материалы и письменная часть доступны без сети. Установку зависимостей и сетевые действия выполняют отдельно, когда доступна сеть. Целевая версия — 0.160.0. Документальная сверка: 2026-10-05; она не заменяет протокол запуска на вашей ОС.
