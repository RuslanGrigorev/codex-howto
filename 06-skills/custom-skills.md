# Урок 6: Повторяемые действия и Skills в Codex CLI

## Цель урока
Научиться создавать, валидировать и использовать пользовательские навыки (Skills) для Codex CLI. Понять разницу между встроенными командами CLI и подключаемыми навыками, а также правила безопасности при распространении навыков.

## Предпосылки
- Пройдены уроки по основам Codex CLI, AGENTS.md и управлению сессиями.
- Понимание формата YAML и разметки Markdown.

## Что такое Skill в Codex CLI

**Skill (навык)** — это модульный набор инструкций, шаблонов и правил, оформленный в виде папки с главным файлом `SKILL.md`.

Навыки позволяют:
- Переиспользовать сложные контекстные инструкции между проектами и задачами.
- Обучать агента специализированным рабочим процессам (например, ревью кода, миграции баз данных, TDD).
- Подключать навыки по требованию (on-demand), экономя контекстное окно модели.

### Структура навыка

```text
.agents/skills/my-awesome-skill/
├── SKILL.md                 # Обязательный файл с инструкциями и frontmatter
├── scripts/                 # Опциональные вспомогательные скрипты
└── templates/               # Опциональные шаблоны
```

### Формат файла `SKILL.md`

Каждый `SKILL.md` обязан начинаться с блока YAML frontmatter:

```markdown
---
name: my-awesome-skill
description: Экспертный навык для автоматизации проверок безопасности и структуры репозитория
---

# My Awesome Skill

## Назначение
Подробное описание того, когда и как агент должен активировать этот навык.

## Шаги выполнения
1. Проверить входные данные.
2. Сформировать план изменений.
3. Провести верификацию.
```

### Отличие навыков от встроенных команд

| Характеристика | Встроенная команда CLI | Пользовательский навык (Skill) |
|---|---|---|
| **Где определена** | В исходном коде бинарника Codex CLI | В `.agents/skills/` или `~/.codex/skills/` |
| **Синтаксис** | Флаги и подкоманды (`codex resume`, `codex --version`) | Естественный язык или имя навыка |
| **Изменение** | Требует обновления CLI | Создается и редактируется пользователем за секунды |
| **Уровень доверия** | Системный | Локальный (требует проверки на отсутствие вредоносных инструкций) |

> [!WARNING]
> **Требования безопасности для навыков:**
> - Навык **НЕ ДОЛЖЕН** содержать жестко зашитых абсолютных путей (`C:\Users\...` или `/home/...`). Все пути должны быть относительными!
> - Навык **НЕ ДОЛЖЕН** запрашивать или раскрывать секреты (API-ключи, токены).
> - Имя навыка (`name`) должно быть компактным идентификатором в нижнем регистре (kebab-case).

## Практическое упражнение: `custom-skill`

В этом упражнении вам нужно реализовать валидатор `SkillValidator`, который:
1. Проверяет наличие обязательного файла `SKILL.md`.
2. Валидирует YAML frontmatter (наличие полей `name` и `description`).
3. Блокирует навыки с некорректным форматом `name` (только латиница в нижнем регистре, цифры и дефисы).
4. Защищает от утечек: отклоняет навыки, содержащие абсолютные пути к файловой системе автора.

### Запуск проверки упражнения

```bash
python scripts/verify.py --exercise custom-skill
```
