# Создание локального навыка Codex

## Чему вы научитесь

Разобраться в структуре навыка и отличать локальную проверку файлов от его фактического вызова.

## Что нужно перед началом

Сначала пройдите: [Начало: что изучаем и как проверяем результат](../01-start/overview.md). Учебные файлы входят в поставку. Установленные программы и доступ к модели требуются только для соответствующей практики.

Навык упаковывает повторяемую процедуру и подключаемые материалы. В репозитории используйте `.agents/skills/NAME/SKILL.md`; пользовательские навыки размещаются отдельно. Для первого примера достаточно метаданных и короткой проверяемой процедуры.

```markdown
---
name: course-review
description: Проверка небольшого учебного изменения с отчётом на русском.
---
Прочитай требования задачи. Проверь diff и результаты независимых тестов.
Не изменяй файлы при ревью. Отделяй найденные ошибки от непроверенных предположений.
```

Вызывайте собственный навык явно через `$course-review`. Это не встроенная `/course-review`. В `description` опишите, когда навык нужен; подробные справочники храните рядом и подключайте по необходимости, не загружайте весь курс в каждый запрос.

## Практика

Упражнение `custom-skill` проверяет учебные правила структуры навыка. Дополнительно создайте настоящий SKILL.md в отдельном проекте, убедитесь в обнаружении через интерфейс и вызовите его. Оцените выполнение процедуры по diff и тестам, а не по одному факту появления имени.

## Проверяемое упражнение

Выполняйте команды из корня репозитория или из `source` готового офлайн-пакета. Подготовка не перезаписывает существующую работу.

```bash
python scripts/verify.py --prepare custom-skill
# Измените файлы в .learning/workspaces/custom-skill
python scripts/verify.py --exercise custom-skill --workspace .learning/workspaces/custom-skill
```

Проверка запускает независимый `examples/custom-skill/test.py`, а не тест из рабочей папки. Эталон находится в `examples/custom-skill/solution`; открывайте его после собственной попытки. Тестируемый Python-код исполняется на вашей машине: запускайте только доверенные учебные файлы. Ограничение пути не является OS-песочницей.

## Что считается выполнением в Codex

Без модели доступны весь текст, вопросы, исходники и локальные тесты. Они не подтверждают работу CLI. Для практики сохраните версию `codex --version`, модель, провайдера и обезличенный результат реального запуска. Отметку можно внести через `scripts/progress.py` после проверки, согласно [правилам валидации](../reference/validation.md). Самоотчёт ученика не заменяет выпускные доказательства проекта.
