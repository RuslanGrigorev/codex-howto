# Создание локального навыка Codex

## Чему вы научитесь

- Создавать и структурировать пользовательские навыки (Skills) для Codex CLI.
- Разрабатывать спецификацию `SKILL.md` с валидным YAML-frontmatter (поля `name`, `description`).
- Отличать явный вызов навыка через префикс `$skill-name` от встроенных слеш-команд `/command`.
- Выполнять независимую валидацию структуры навыка через упражнение `custom-skill`.

## Что нужно перед началом

- Понимание механизма обнаружения навыков из урока [Обнаружение и вызов skill](create.md) (схема D05).
- Каталог `.agents/skills/` в корне проекта или глобальная директория `~/.codex/skills/`.
- Установленный Codex CLI 0.160.0 или изучение справочника навыков.

## Схема процесса

Жизненный цикл обнаружения и вызова пользовательского навыка:

```
[Пользовательский ввод: "$code-audit проверь модуль storage"]
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│              Диспетчер навыков Codex CLI               │
├────────────────────────────────────────────────────────┤
│ 1. Сканирование каталогов: .agents/skills/ и ~/.codex/ │
│ 2. Парсинг YAML frontmatter в SKILL.md                 │
│ 3. Сверка имени name: "code-audit"                     │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│              Инжекция инструкций в контекст            │
├────────────────────────────────────────────────────────┤
│ - Системный промпт дополняется телом SKILL.md          │
│ - Дополнительные материалы (references/) загружаются    │
│   только по явному требованию задачи                   │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
[Модель выполняет регламентированную процедуру ревью]
```

## Команды и параметры

Синтаксис и вызов пользовательских навыков:

```bash
# Вызов навыка в интерактивной сессии через префикс доллара
$course-review

# Вызов навыка с аргументами задачи
$course-review src/payment.py --strict

# Запуск подготовки и проверки автономного упражнения
python scripts/verify.py --prepare custom-skill
python scripts/verify.py --exercise custom-skill --workspace .learning/workspaces/custom-skill
```

Пример корректного файла `.agents/skills/course-review/SKILL.md`:

```markdown
---
name: course-review
description: Автоматизированная проверка кода и тестов с отчетом на русском языке.
---

## Инструкция по выполнению ревью
1. Изучи требования задачи и связанный diff Git.
2. Запусти локальные независимые тесты.
3. Составь отчет со следующей структурой:
   - Обнаруженные дефекты (P0/P1 блокеры).
   - Замечания по качеству (P2/P3).
   - Итоговый статус (APPROVE / REJECT).
4. Не изменяй файлы проекта во время ревью.
```

## Разбор примера

Рассмотрим вызов навыка ревью для проверки модуля:

1. Пользователь вводит: `$course-review проведи аудит src/auth.py`.
2. Codex CLI считывает манифест из `.agents/skills/course-review/SKILL.md`.
3. Агент переключается в регламент ревью:
   - Анализирует код файла `src/auth.py`.
   - Запускает тесты `pytest tests/test_auth.py`.
   - Формирует структурированный отчет на русском языке.
4. Агент не пытается рефакторить код, так как в правилах навыка четко указано: «Не изменяй файлы проекта во время ревью».

## Ограничения и безопасность

- Вызов `$skill-name` не заменяет слеш-команды ядра: слеш-команды (`/status`, `/compact`) обрабатываются TUI-клиентом, а навыки расширяют системный промпт LLM.
- Не включайте секреты, пароли или токены API в текст `SKILL.md` или вспомогательные файлы навыка.
- Избегайте слишком объемных описаний в секции `description`: это поле считывается при индексации всех навыков и перегружает контекст при большом количестве установленных расширений.

## Типовые ошибки

1. **Использование слеша вместо знака доллара**: попытка вызвать `/course-review` вместо `$course-review`.
2. **Невалидный YAML frontmatter**: отсутствие разделителей `---` в начале и конце метаданных или ошибки отступов.
3. **Несоответствие имени каталога и поля name**: расположение навыка в папке `skills/review/`, когда в поле `name` указано `my-reviewer`.

## Практика

1. Подготовьте собственный навык в `.learning/workspaces/custom-skill/.agents/skills/custom-skill/SKILL.md`.
2. Добавьте валидный frontmatter с полями `name` и `description`.
3. Выполните проверку структуры скриптом курса:
   ```bash
   python scripts/verify.py --prepare custom-skill
   python scripts/verify.py --exercise custom-skill --workspace .learning/workspaces/custom-skill
   ```
4. Убедитесь, что независимый тест `examples/custom-skill/test.py` подтверждает корректность разметки и возвращает `PASS`.

## Самопроверка

<details>
<summary>Подсказка и критерии самопроверки</summary>

- Убедитесь, что файл начинается строго с трех дефисов `---` на первой строке.
- Поля `name` и `description` обязательны и содержат непустые строковые значения.
- Критерий успешности: `python scripts/verify.py --exercise custom-skill` возвращает код `0` (PASS).

</details>

## Источники и доступность

Практика требует установленного Codex и доступной выбранной модели. Без модели выполните разбор примера и подготовьте ожидаемый результат; реальный запуск остаётся невыполненным. Целевая версия — 0.160.0. Документальная сверка: 2026-10-05; она не заменяет протокол запуска на вашей ОС.
