# Диагностика навыка и наставник $learn

## Чему вы научитесь

- Выявлять и устранять причины, по которым навык Codex CLI не обнаруживается или игнорируется.
- Проверять список зарегистрированных навыков через команду `/skills` в TUI.
- Понимать архитектуру и методику интерактивного наставника `$learn` в этом курсе.
- Диагностировать ошибки в синтаксисе YAML-frontmatter и правах доступа к файлам навыков.

## Что нужно перед началом

- Понимание базовой структуры каталога `.agents/skills/<name>/SKILL.md`.
- Установленный Codex CLI 0.160.0.
- Репозиторий курса с активным файлом конфигурации каталога `course.json`.

## Команды и параметры

Команды инспекции и отладки навыков:

```text
# Просмотр всех загруженных и активных навыков в сессии
/skills

# Проверка контекста и системного промпта
/status

# Вызов интерактивного наставника по конкретному уроку курса
$learn workflow.plan-goal
```

Команды файловой проверки целостности навыка в консоли:

```bash
# Проверка наличия манифеста и корректного регистра имени
ls -la .agents/skills/learn/SKILL.md

# Валидация YAML-заголовка навыка через Python
python -c "import yaml, pathlib; txt = pathlib.Path('.agents/skills/learn/SKILL.md').read_text(encoding='utf-8'); print(yaml.safe_load(txt.split('---')[1]))"
```

## Разбор примера

Рассмотрим случай, когда пользователь пытается вызвать наставника `$learn`, но агент отвечает: «Я не знаю такого навыка»:

1. Запускаем сессию и вводим команду `/skills`.
2. В списке зарегистрированных расширений навык `learn` отсутствует.
3. Проверяем файловую систему:
   - Обнаруживаем, что файл назван `skill.md` (в нижнем регистре) вместо `SKILL.md` (на Linux это критично!).
   - Или обнаруживаем, что первая строка файла содержит пробел перед `---`.
4. Исправляем имя на `.agents/skills/learn/SKILL.md` и убираем лишние пробелы.
5. Перезапускаем сессию: `/skills` теперь отображает `learn: Персональный интерактивный наставник курса`.
6. Вызываем `$learn start.overview`: наставник загружает урок и начинает диалог.

## Ограничения и безопасность

- Наставник `$learn` предназначен для помощи и объяснений, но не должен решать упражнения за ученика или генерировать фиктивные ответы для тестов.
- Навык не должен требовать внешнего сетевого подключения для чтения локальных файлов уроков: весь контент курса доступен офлайн.
- Избегайте циклических зависимостей, когда навык A ссылается на навык B, а тот повторно вызывает навык A.

## Типовые ошибки

1. **Ошибки регистра в имени файла**: наименование `skill.md` вместо строгого `SKILL.md`, приводящее к сбою поиска в Linux и macOS.
2. **Случайные дубликаты**: размещение навыка с одинаковым именем в `.agents/skills/` и `~/.codex/skills/`, порождающее неопределенность приоритета.
3. **Фальсификация результатов**: попытка попросить наставника обойти тесты ради зеленого статуса PASS.

## Практика

1. Проверьте список активных навыков в вашем окружении с помощью команды `/skills`.
2. Намеренно переименуйте файл одного из учебных навыков в `skill.txt` и убедитесь, что CLI перестал его видеть.
3. Верните правильное имя `SKILL.md` и проверьте успешную регистрацию.
4. Вызовите наставника `$learn workflow.plan-goal`, задайте вопрос по уроку и проанализируйте качество методической поддержки.

- Критерий успешности: навык стабильно обнаруживается и исполняет инструкции при любых перезапусках CLI.

## Проверка знаний

Ответьте на вопросы внизу страницы. В исходном репозитории они доступны в [файле вопросов](debug.quiz.json). Правильные ответы подтверждают понимание; выполнение практики фиксируется отдельно.

Практика требует установленного Codex и доступной выбранной модели. Без модели выполните разбор примера и подготовьте ожидаемый результат; реальный запуск остаётся невыполненным. Целевая версия — 0.160.0. Документальная сверка: 2026-10-05; она не заменяет протокол запуска на вашей ОС.
