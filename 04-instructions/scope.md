# Область действия AGENTS.md и вложенные инструкции

## Чему вы научитесь

Размещать правила рядом с кодом, к которому они относятся, и проверять их загрузку.

## Что нужно перед началом

Урок об AGENTS.md и отдельная учебная копия проекта.

## Как это работает

Инструкции бывают общими и относящимися к отдельной части дерева. Правило «для Python запускать этот тест» не должно случайно управлять всем репозиторием, если в нём есть другие компоненты.

Начните с короткого корневого `AGENTS.md`, затем добавьте вложенный файл для конкретной папки. Избегайте противоречий: более подробная инструкция должна уточнять локальный процесс, а не скрыто менять безопасность. Доступный размер инструкций и порядок обнаружения имеют значение; не складывайте в один файл весь учебник.

Проверка должна показывать, какие правила были использованы в выбранном каталоге. Само существование `AGENTS.md` ещё не подтверждает его загрузку в уже открытой сессии.

## Разобранный пример

Корневой файл может содержать:

```markdown
# Работа с учебным проектом
Отвечай по-русски. Не изменяй независимые тесты.
Перед правкой назови файл и способ проверки.
```

В `sample/AGENTS.md` добавьте локальное правило: «Для sample сначала прочитай README.md этой папки». Это пример учебной инструкции, не новая настройка TOML.

## Самостоятельная практика

Создайте два уровня инструкций в учебной копии. Запустите новую сессию из корня и отдельно из вложенной папки. Попросите назвать применимые правила и проверить один безопасный файл.

Измените одно локальное правило и повторите в новой сессии. Не оценивайте результат только по красоте ответа: проверьте, выполнил ли агент требуемое чтение.

## Ожидаемый результат

Понятна область каждого файла инструкций; изменение локального правила не требует копирования всего корневого текста.

## Разбор решения

<details>
<summary>Показать после самостоятельной попытки</summary>

Корень задаёт язык и общие границы. Вложенная папка уточняет локальный порядок. После изменения правил запускают новую проверку и записывают рабочий каталог. Если клиент не обнаружил файл, сначала проверяют путь и имя, а не удлиняют текст инструкции.

</details>

## Типовые ошибки

Дублировать все правила на каждом уровне; смешивать конфигурацию прав и текстовые инструкции; считать старую сессию доказательством загрузки нового файла.

## Проверка знаний

Ответьте на вопросы внизу страницы. В исходном репозитории они доступны в [файле вопросов](scope.quiz.json). Правильные ответы подтверждают понимание; выполнение практики фиксируется отдельно.
