# AGENTS.md: инструкции проекта и области действия

## Чему вы научитесь

Описать команды и правила проекта в AGENTS.md, не превращая инструкции в хранилище секретов.

## Что нужно перед началом

Сначала пройдите: [Начало: что изучаем и как проверяем результат](../01-start/overview.md). Учебные файлы входят в поставку. Установленные программы и доступ к модели требуются только для соответствующей практики.

Создайте краткий `AGENTS.md` с назначением проекта, командами проверки, ограничениями изменений и правилами оформления. Не помещайте туда секреты, машинно-зависимые абсолютные пути и непроверенные команды. Инструкции должны описывать реальный проект, а не желаемую архитектуру.

```markdown
# Работа над учебным проектом
Объясняй изменения по-русски. Команды и имена API оставляй в оригинале.
## Команды сборки и тестов
Проверяй задачу независимым тестом из examples.
## Правила оформления
Не меняй тесты ради успеха. Не публикуй изменения без отдельного запроса.
```

Codex учитывает расположение инструкций. Перед разбором вложенного каталога нужно понимать, какие более конкретные правила на него распространяются. Не объединяйте автоматически все найденные файлы в один текст без учёта области действия. Детали загрузки и override-файлов сверяйте с официальным руководством.

## Практика

Вспомогательный валидатор `agents-rules` проверяет **принятое в нашем упражнении** наличие двух секций, отсутствие подозрительных токенов и локальных абсолютных путей. Это не официальная схема AGENTS.md: Codex не требует именно этих русских заголовков.

После локального упражнения отдельно проверьте реальное применение инструкций: попросите Codex объяснить команды проверки в подготовленном проекте и сопоставьте ответ с файлом. Исправьте расплывчатые или противоречивые правила.

## Проверяемое упражнение

Выполняйте команды из корня репозитория или из `source` готового офлайн-пакета. Подготовка не перезаписывает существующую работу.

```bash
python scripts/verify.py --prepare agents-rules
# Измените файлы в .learning/workspaces/agents-rules
python scripts/verify.py --exercise agents-rules --workspace .learning/workspaces/agents-rules
```

Проверка запускает независимый `examples/agents-rules/test.py`, а не тест из рабочей папки. Эталон находится в `examples/agents-rules/solution`; открывайте его после собственной попытки. Тестируемый Python-код исполняется на вашей машине: запускайте только доверенные учебные файлы. Ограничение пути не является OS-песочницей.

## Что считается выполнением в Codex

Без модели доступны весь текст, вопросы, исходники и локальные тесты. Они не подтверждают работу CLI. Для практики сохраните версию `codex --version`, модель, провайдера и обезличенный результат реального запуска. Отметку можно внести через `scripts/progress.py` после проверки, согласно [правилам валидации](../reference/validation.md). Самоотчёт ученика не заменяет выпускные доказательства проекта.
