# Модуль 4: Инструкции и контекст проекта (instructions.agents-md)

## Цель урока
- Понять назначение и структуру файла `AGENTS.md` в экосистеме Codex CLI.
- Научиться разграничивать постоянные инструкции проекта, временные задачи из промпта и глобальные настройки.
- Освоить иерархию инструкций при работе с монорепозиториями и вложенными пакетами.
- Избежать распространенных антипаттернов: утечки токенов, хардкода персональных путей и раздувания контекста.

---

## Предпосылки
- Пройден модуль [03-safety](../03-safety/permissions.md).
- Понимание базовой структуры репозитория.

---

## 1. Что такое AGENTS.md

В Codex CLI файл `AGENTS.md` в корне репозитория служит единым стандартом передачи контекста и правил разработки AI-ассистенту.

Когда вы запускаете:
```bash
codex "Реализуй новую функцию"
```
Codex CLI автоматически считывает `AGENTS.md` и учитывает его указания как высокоприоритетные системные правила при планировании, редактировании файлов и запуске тестов.

---

## 2. Разделение зон ответственности

Важно четко различать уровни контекста:

1. **Глобальные настройки пользователя (`~/.codex/config.toml`):**
   Личные предпочтения разработчика, провайдеры моделей, токены API. Никогда не включаются в репозиторий проекта.
2. **Инструкции проекта (`AGENTS.md`):**
   Правила для любого разработчика или агента, работающего с данным кодом (команды тестов, соглашения об именовании, архитектурные ограничения). Хранятся в Git.
3. **Временная задача (User Prompt):**
   Конкретное текущее поручение («исправь опечатку в заголовке», «добавь валидацию email»).
4. **Учебный наставник (`.agents/skills/learn/SKILL.md`):**
   Интерактивный учебный навык курса (`$learn`), который не навязывается разработчикам основного репозитория, а активируется по запросу.

---

## 3. Рекомендуемая структура AGENTS.md

Хороший `AGENTS.md` лаконичен и содержит только прикладные, воспроизводимые факты:

```markdown
# Инструкции для агентов разработки

## Архитектура
- Язык: Python 3.11+
- Архитектура: модульная, без внешних сетевых зависимостей

## Команды проверки и тестов
- Запуск автономной верификации: `python scripts/verify.py --profile offline`
- Запуск одного упражнения: `python scripts/verify.py --exercise <id>`

## Правила оформления кода
- Только стандартная библиотека Python (stdlib), если иное не указано
- Все пути должны быть относительными
- Не коммитить временные файлы и логи

## Запрещенные действия
- Не изменять файлы за пределами репозитория
- Не добавлять зависимости без явного требования в задаче
```

## 4. Иерархия инструкций (Subdirectories)

Если ваш проект содержит независимые подсистемы (например, `frontend/` и `backend/`), во вложенном каталоге можно создать локальный `AGENTS.md`:

```text
my-project/
├── AGENTS.md                 # Общие правила репозитория
├── backend/
│   └── AGENTS.md             # Специфика Python/FastAPI
└── frontend/
    └── AGENTS.md             # Специфика TypeScript/React
```

При работе с файлами в `backend/` Codex объединяет корневой и локальный файлы, отдавая приоритет правилам `backend/AGENTS.md`.

---

## 5. Типичные антипаттерны

- **Секреты и ключи:** Никогда не пишите `OPENAI_API_KEY=sk-...` в `AGENTS.md`. Файл попадает в Git!
- **Абсолютные пути:** Пути вида `C:\Users\John\...` или `/home/alice/...` ломают воспроизводимость на машинах других разработчиков.
- **«Война стилей» и длинные трактаты:** Не перегружайте файл длинными теоретическими рассуждениями — это отнимает полезное контекстное окно модели.

## Практическое упражнение: agents-rules

В каталоге `examples/agents-rules` находится валидатор содержимого `AGENTS.md`. Ваша задача — доработать функцию `validate_agents_content`, которая проверяет наличие ключевых секций и блокирует секреты и персональные пути.

### Инструкция:
1. Перейдите в каталог упражнения `.learning/workspaces/agents-rules` (или скопируйте заготовку из `examples/agents-rules/starter`).
2. Доработайте файл `validator.py`.
3. Запустите автономную проверку:
```bash
python scripts/verify.py --exercise agents-rules
```

### Подсказки:
1. Используйте регулярные выражения для поиска секций `## Команды` и `## Правила`.
2. Проверяйте шаблоны токенов `sk-`, `ghp_` и путей `[A-Za-z]:\\Users\\` или `/home/`.
