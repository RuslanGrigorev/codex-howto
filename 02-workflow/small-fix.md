# Точечное исправление бага (workflow.small-fix)

## Цель урока
Научиться формулировать задачу для Codex CLI, запрашивать план и diff изменений, а также проверять результаты тестов перед подтверждением правок.

## Предпосылки
- Установлен Python 3.11+.
- Доступен терминал в рабочей директории проекта.

## 1. Сформулируйте ограниченную задачу
При работе с Codex CLI ключевой навык — ограничение контекста и четкая постановка цели. Не просите модель «переписать модуль». Задайте точный сценарий:
```bash
codex "В модуле math_utils функция calculate_discount падает при отрицательном значении. Исправь валидацию и добавь тест."
```

## 2. Анализ diff и плана
Перед применением изменений Codex генерирует предлагаемый diff. Обратите внимание:
- Затрагивает ли diff только ожидаемые файлы?
- Нет ли случайного изменения сторонних конфигураций?
- Запущены ли юнит-тесты?

## Практическое упражнение (small-fix)
В каталоге `examples/small-fix` находится функция расчета скидки, в которой пропущена обработка граничных условий (скидка не может превышать 100% и быть меньше 0%).

### Задание:
1. Перейдите в рабочий каталог упражнения: `.learning/workspaces/small-fix`.
2. Исправьте ошибку в файле `discount.py`.
3. Запустите локальную автономную проверку:
```bash
python scripts/verify.py --exercise small-fix
```

## Подсказки
1. Скидка `discount` должна быть числом от `0.0` до `1.0`.
2. Если передано значение меньше 0 или больше 1, функция должна выбрасывать `ValueError("Некорректная скидка")`.

## Эталонное решение
Решение доступно в файле [examples/small-fix/solution/discount.py](../examples/small-fix/solution/discount.py).
