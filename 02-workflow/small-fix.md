# Ограниченное исправление: запрос, diff и тест

## Чему вы научитесь

Исправить небольшую ошибку, проверить независимый тест и объяснить каждый изменённый участок.

## Что нужно перед началом

Сначала пройдите: [Начало: что изучаем и как проверяем результат](../01-start/overview.md). Учебные файлы входят в поставку. Установленные программы и доступ к модели требуются только для соответствующей практики.

Хороший запрос задаёт воспроизводимую ошибку, допустимые изменения и проверку результата. В упражнении `apply_discount(price, discount)` скидка задаётся долей от 0 до 1: для 100 и 0.2 результат равен 80. Границы 0 и 1 допустимы; значения вне диапазона должны приводить к `ValueError`.

```text
Исследуй discount.py и тесты. Исправь только расчёт скидки и проверку её диапазона.
Не меняй тесты. Сначала объясни причину ошибки, затем предложи минимальное исправление.
После изменения запусти независимую проверку и покажи результат.
```

Сначала самостоятельно вызовите тест и зафиксируйте ошибку. Во время работы проверяйте не только ответ модели, но и изменённые файлы. «Тесты должны пройти» не равно выполненной команде с кодом 0.

## Подсказка

Скидка уменьшает исходную цену: рассмотрите оставшуюся долю, а не величину скидки. Не округляйте промежуточное выражение без требования. После исправления проверьте минимальность diff через Git в одноразовом учебном репозитории. Готовый эталон предназначен для разбора после попытки, а не для автоматического зачёта.

## Проверяемое упражнение

Выполняйте команды из корня репозитория или из `source` готового офлайн-пакета. Подготовка не перезаписывает существующую работу.

```bash
python scripts/verify.py --prepare small-fix
# Измените файлы в .learning/workspaces/small-fix
python scripts/verify.py --exercise small-fix --workspace .learning/workspaces/small-fix
```

Проверка запускает независимый `examples/small-fix/test.py`, а не тест из рабочей папки. Эталон находится в `examples/small-fix/solution`; открывайте его после собственной попытки. Тестируемый Python-код исполняется на вашей машине: запускайте только доверенные учебные файлы. Ограничение пути не является OS-песочницей.

## Что считается выполнением в Codex

Без модели доступны весь текст, вопросы, исходники и локальные тесты. Они не подтверждают работу CLI. Для практики сохраните версию `codex --version`, модель, провайдера и обезличенный результат реального запуска. Отметку можно внести через `scripts/progress.py` после проверки, согласно [правилам валидации](../reference/validation.md). Самоотчёт ученика не заменяет выпускные доказательства проекта.
