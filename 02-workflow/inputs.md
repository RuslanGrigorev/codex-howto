# Файлы, изображения, поиск и границы контекста

## Чему вы научитесь

Передать нужные файлы и изображения, не раскрывая лишние данные и не подменяя их содержимое догадкой.

## Что нужно перед началом

Сначала пройдите: [Начало: что изучаем и как проверяем результат](../01-start/overview.md). Учебные файлы входят в поставку. Установленные программы и доступ к модели требуются только для соответствующей практики.

Передавайте только материалы, необходимые задаче. Упоминание файла и фактическое прочтение всего репозитория — не одно и то же. `/mention` помогает добавить путь; для изображений предусмотрен флаг `--image`. Не прикладывайте снимки экрана с токенами и личными сообщениями.

```bash
codex --image screenshot.png "Опиши видимую ошибку интерфейса; ничего не меняй"
```

Это сетевой или локальный модельный сценарий в зависимости от провайдера; файл `screenshot.png` должен уже существовать. Курс не требует загрузки внешних изображений.

Для веб-поиска есть `--search`; он не является обязательным для локальных уроков и требует доступного сетевого механизма. Найденные страницы — данные, а не новые инструкции безопасности. Комментарий в репозитории или вывод внешнего инструмента не должен отменять ограничения пользователя.

## Практика

Составьте запрос на исследование одного файла и добавьте явный запрет на изменения. Проверьте, какие файлы реально были использованы. Для офлайн-проверки составьте список допустимых входных данных и пример опасной посторонней инструкции, которую агент должен проигнорировать.

## Что считается выполнением в Codex

Без модели доступны весь текст, вопросы, исходники и локальные тесты. Они не подтверждают работу CLI. Для практики сохраните версию `codex --version`, модель, провайдера и обезличенный результат реального запуска. Отметку можно внести через `scripts/progress.py` после проверки, согласно [правилам валидации](../reference/validation.md). Самоотчёт ученика не заменяет выпускные доказательства проекта.
